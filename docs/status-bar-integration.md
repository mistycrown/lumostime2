# 状态栏自适应背景功能

## 功能说明

应用现在支持根据背景图片自动调整手机状态栏的颜色样式，让状态栏与应用标题栏更好地融合。

## 工作原理

1. **背景分析**：当用户更改背景图片时，系统会自动分析背景图片顶部区域的颜色
2. **亮度计算**：使用感知亮度公式计算背景的平均亮度
3. **样式调整**：
   - 如果背景是深色的（亮度 < 0.5），状态栏使用浅色图标
   - 如果背景是浅色的（亮度 ≥ 0.5），状态栏使用深色图标

## 技术实现

### 新增服务

#### `statusBarService.ts`
负责管理状态栏样式：
- 分析背景图片的主色调和亮度
- 根据背景自动调整状态栏图标颜色
- 提供重置和查询当前样式的方法

#### `backgroundService.ts` 更新
在原有背景管理功能基础上：
- 集成状态栏服务
- 在切换背景时自动更新状态栏
- 在调整背景透明度时同步更新状态栏

### 使用方式

功能已自动集成，无需额外配置。当用户在设置中更改背景图片时，状态栏会自动调整。

### 调试

在浏览器控制台中可以使用以下命令进行调试：

```javascript
// 查看当前状态栏样式
statusBarService.getCurrentStyle()

// 手动测试特定背景
statusBarService.updateForBackground('/background/night.webp')

// 重置状态栏
statusBarService.reset()
```

## 兼容性

- 仅在 Android 和 iOS 平台上生效
- 在 Web 浏览器中会自动跳过状态栏设置
- 需要 `@capacitor/status-bar` 插件支持

## 注意事项

1. 状态栏分析只针对图片顶部区域（前100像素），以匹配状态栏实际显示位置
2. 使用采样算法提高性能，避免分析每个像素
3. 如果图片加载失败，会自动回退到默认的浅色状态栏
