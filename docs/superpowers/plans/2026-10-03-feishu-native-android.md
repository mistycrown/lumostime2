# 手机与电脑统一飞书本机连接

**目标：** Android 与 Electron 使用同一专属应用创建、设备授权、令牌刷新和日历同步实现，手机不依赖远程连接服务。

**执行方式：** 用户已确认；native 实施，不使用子代理、不追加审批。

**架构：** 将当前飞书执行逻辑提取为平台无关的共享模块。Electron 保留既有安全存储与 SQLite 适配；Android 使用内存执行器、原生 HTTP、Keystore AES-GCM 加密快照和系统浏览器。飞书凭证仅在内部执行逻辑的内存中处理，不进入 UI 状态、日志、localStorage 或普通备份。

**约束：** UTF-8；不编译 Android；保留已有未提交改动；只提交本次改动。
