# 节点分类拖动管理

执行方式：按照仓库要求由当前代理 native 执行，无额外确认或子代理。

目标：以极简印刷风格的可搜索分类浮层替换原生下拉框，并通过右上角管理入口提供自动换行的胶囊拖动归类和排序。

设计：目录和详情共用 `NodeCategorySelect`；管理页 `NodeManageView` 使用 Pointer Events，同时支持鼠标与触屏。节点及分类数组自身的顺序就是手动顺序，沿用现有原子持久化、备份和同步通道，无新增独立排序数据。未分类固定在末尾。点击胶囊可通过选择器与前后移动按钮完成同样操作。

实现与验证：
- [x] 在 `nodeUtils.ts` 增加移动节点和重排工具；测试跨分类、组内首尾位置、无效目标与元数据保留。
- [x] 在 `NodeContext.tsx` 暴露移动/排序动作；创建分类选择器并替换目录和详情的原生控件。
- [x] 实现胶囊管理界面：节点归类/排序、分类排序、拖动反馈、边缘滚动、取消、搜索和键盘替代操作；目录新增管理入口和手动排序。
- [x] 扩展真实渲染器检查分类浮层、鼠标与触屏拖动、取消、分类顺序和重新加载；检查移动端与桌面截图。
- [x] 运行相关 Vitest、生产构建、Android 资源同步，检查差异并仅提交本任务文件。

验证结果：37 项 Vitest 通过；真实 React/Electron 页面中的原生鼠标与触屏拖动、取消、选择器、排序和重新加载检查通过；手机与桌面截图已核对中文及布局。`npm run build` 和 `npx cap sync android` 通过；相对当前 HEAD 无新增 TypeScript 诊断。

约束：UTF-8；不编译 Android；不修改用户现有同步设置变更；不改变备注节点语法；不增加菜单说明文案。
