# 节点功能实现清单

**目标：** 实现用户提供的节点 PRD，入口位于设置「内容」，详情沿用标签详情的极简印刷风格。
**执行：** Native，由当前 agent 实现，不额外请求设计批准、不使用子代理。
**架构：** `Log.note` 中的 `[[名称]]` 是唯一关系来源；`NoteNode` 只保存名称、别名、简介和时间戳。元数据接入 DataContext / IndexedDB / JSON 与云端备份，关系在内存中索引。
**技术：** React、TypeScript、现有 DetailTimelineCard、现有 AI 配置。

- [x] `src/utils/nodeUtils.ts`：解析、发现、索引、共现、候选转换与改名；验证非法语法、重复链接、别名重叠和已有关联保护。
- [x] 持久化元数据、自动发现节点、旧备份兼容、新备份恢复与清空；改名时原子保存节点、备注与飞书同步队列。
- [x] 跨页面节点导航，普通备注和清单备注链接，保存后的候选建议。
- [x] 搜索与三种排序；详情、全部记录时间线、共现和候选记录；简介手写 / AI、别名增删改、改名冲突保护。
- [x] 58 项单元测试、节点与同步离线渲染测试、完整生产应用入口与补记烟测、生产构建通过；TypeScript 对比 HEAD 无新增错误。

第一版不加入分类、图谱、输入补全或独立关系表。根据用户后续调整，补记备注输入过程中展示名称/别名匹配建议，点击才转换双链；详情固定标题栏与标签详情对齐，目录使用紧凑双行。UI 沿用纸色底、石色文字、细分隔线、衬线页签。
