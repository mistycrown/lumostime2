# 待办系统日历提醒增强

**Goal:** Android 提醒可选择同步到独立本地系统日历，由日历应用在 LumosTime 退出后提醒。

**Architecture:** 保留现有 AlarmManager 提醒；每个日期提醒增加可选 `calendarSync`。成功落盘后的原生快照负责协调本应用专用日历，按稳定标识增改删，批次原子提交，失败不阻断本地通知。Calendar Provider 自身不负责展示通知，仍需设备的日历应用正常运行并允许通知。

**Tech Stack:** React / TypeScript / Capacitor / Android CalendarContract。

**Execution:** 按 AGENTS.md 由当前代理 native 执行，不询问执行方式，不启动子代理。不编译 Android 应用。

## 约束与设计

- 默认不写系统日历；在提醒弹窗开启开关时申请读写日历权限。
- 使用 ACCOUNT_TYPE_LOCAL 的独立日历，不访问云日历、不修改用户自行创建的事件。
- 日历事件从提醒时刻开始，持续一分钟，零分钟提前提醒；日期来源写入描述。
- 重复快照不重建事件/提醒；改名改期更新，完成、删除、关闭或取消同步清除对应事件。
- 已过去的提醒不新增到日历；已有事件可保留至待办取消提醒，避免反复重建。
- 权限撤销时报告清理/同步受阻；恢复并回到应用后从最新原生快照重试。
- Web/Electron 保持运行期间通知；旧 APK 不展示不可用的日历开关。

## Review Focus

- 重复保存与进程重启不得创建重复事件或重新触发旧提醒。
- 日历权限拒绝、撤销与批处理失败不得阻止原有通知调度。
- 改期、双日期、完成、删除和关闭同步后只修改对应的本应用事件。
- 时区变化重新投影本地时刻；过去/夏令时无效时刻不创建新事件。
- 默认配置和旧 APK 保持兼容，不因加载或备份导入主动请求权限。
