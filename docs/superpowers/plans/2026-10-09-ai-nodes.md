# AI 节点操作实施说明

**目标：** AI 获取完整节点词典，按名称或别名补充简介；不存在的节点在最新实际 Log 中提及并创建；添加备注可以引用词典节点。

**设计：** 复用前台结构化工具调用，增加 `upsert_node`。已有节点默认追加简介，明确修改原文时支持替换。新节点与最新 Log 中的 `[[名称]]` 提及作为一次数据更新，保留原备注。没有 Log、无效 ID、重名别名歧义时返回失败。节点动作保存前后快照，支持撤销与重试。

**实现方式：** 按仓库要求 native 执行，不派发子代理。沿用 src、scripts 和 docs 目录及 UTF-8。
