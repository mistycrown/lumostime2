# 时间线样式设计

## 背景

当前应用的“时间脉络”页面只有一套固定的时间线节点样式。仓库中的 `static/zip` 提供了 7 种可切换的时间线视觉方案，并带有针对节点、连线和偏移参数的调节器。目标是在不改动特殊节点的前提下，把这套能力引入当前项目，并放到“投喂功能 - 样式”Tab 中，作为已验证用户可用的自定义功能。

## 目标

- 在“投喂功能 - 样式”Tab 中新增“时间线样式”卡片。
- 接入参考项目中的 7 种时间线样式：
  - `classic`
  - `vine`
  - `celestial`
  - `track`
  - `stitches`
  - `paw`
  - `music`
- 样式实现严格遵循参考代码的节点与连线逻辑。
- 仅作用于“时间脉络”页面的普通时间记录节点。
- 提供类似当前项目导航栏调节器的交互控件，用于调整当前样式的参数。
- 每种样式独立保存一套参数，切换回来时保留上次配置。

## 非目标

- 不改动目标节点、代办节点、日回顾节点、周回顾节点、月回顾节点。
- 不改动详情页时间线、统计页日程图、Journal 时间线等其他时间线实现。
- 首版不做样式缩略图预览网格。
- 首版不做“全部样式恢复默认值”，只支持“恢复当前样式默认值”。

## 方案选择

采用“样式引擎 + 设置入口 + 局部渲染替换”的方案。

原因：

- 参考项目中的样式不仅是换颜色或换 class，还包含 SVG 连线、节点图标轮换、角度偏移、宽度控制等逻辑。
- 当前 `TimelineView` 已较重，直接把 7 种样式和调节器塞进去会进一步放大维护成本。
- 抽出独立渲染层后，可以只替换普通记录节点的“线 + 点”视觉，不影响现有特殊节点结构。

## 架构设计

### 1. 时间线样式配置层

新增一套时间线样式配置定义，职责包括：

- 定义样式枚举和展示名称。
- 定义每种样式的默认参数。
- 提供读取、更新、重置配置的方法。

参数结构与参考项目保持一致：

- `iconSize`
- `iconAngle`
- `lineWidth`
- `offsetX`
- `timelineWidth`
- `uniformNodes`
- `nodeColor`
- `lineColor`
- `lineOpacity`

### 2. 设置状态层

在全局设置上下文中新增：

- 当前时间线样式 ID
- 各样式参数表

持久化规则：

- 当前样式单独保存。
- 7 种样式的配置表整体保存。
- 未命中配置时回退到参考项目默认值。
- 每种样式单独保存参数，不互相覆盖。

### 3. 样式选择与调节组件

在“投喂功能 - 样式”Tab 中新增“时间线样式”卡片。

卡片包含两部分：

- 样式切换区
  - 不做样式预览网格
  - 采用左右切换按钮
  - 中间显示当前样式名称
  - 固定切换顺序：`classic -> vine -> celestial -> track -> stitches -> paw -> music`
- 调节区
  - 默认折叠
  - 点击“调节”后展开当前样式的参数面板
  - 参数改动后实时保存并生效
  - 提供“恢复当前样式默认值”

调节器交互外观参考当前项目导航栏调节器的风格，而不是直接照搬参考项目面板样式。

### 4. 普通节点样式渲染层

将“普通记录节点的节点与连线”抽为独立渲染逻辑。

职责：

- 根据当前 `theme + config + index` 渲染连线
- 根据当前 `theme + config + index` 渲染节点图标或圆点
- 严格复用参考代码中的线条和节点逻辑

特殊节点继续沿用 `TimelineView` 现有实现，不接入这套渲染层。

## 作用范围

仅替换“时间脉络”页面普通时间记录节点的外观，包括：

- 中间的节点
- 节点之间的连线

保留不变的内容：

- 左侧时间标记
- 右侧正文、标签、图片、反应区等内容布局
- 特殊节点的视觉与结构

## 参考逻辑复用要求

必须严格复用参考项目中的以下逻辑：

- 7 种主题定义
- 每种主题默认参数
- `renderLine` 中的 SVG/虚线/轨道/多线实现
- `renderNode` 中的图标选择逻辑
- 节点轮换与角度偏移规则
- `uniformNodes` 的行为

允许按当前项目做的适配：

- 与 `SettingsContext` 的接入
- 与 toast、按钮、卡片外观的一致化
- 时间脉络页面已有布局的挂接方式

## 数据流

1. 用户在“投喂功能 - 样式”Tab 切换时间线样式。
2. 当前样式 ID 写入设置上下文和本地存储。
3. 用户展开调节器修改参数。
4. 当前样式对应的参数写入配置表并持久化。
5. “时间脉络”页面读取当前样式和当前样式配置。
6. 普通记录节点按配置重新渲染节点与连线。

## 验收标准

- 7 种样式全部可切换。
- 切换后仅普通记录节点外观变化。
- 特殊节点外观保持不变。
- 每种样式独立保存参数。
- 参数变更可实时生效。
- 刷新或重启后样式和参数仍保留。
- 小屏设备下节点与正文不重叠。
- `npm run build` 通过。

## 风险与控制

- `TimelineView` 当前体量较大：
  - 通过抽离普通节点样式渲染层控制复杂度。
- 偏移和宽度参数可能导致布局穿插：
  - 需要为参数范围设置合理上下限。
- 参考代码与当前页面结构不同：
  - 只迁移节点与连线逻辑，不迁移整体页面排版。
