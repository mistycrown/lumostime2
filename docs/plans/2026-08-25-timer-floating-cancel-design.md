# 悬浮计时取消菜单设计

## 目标

当存在进行中的计时时，用户可长按屏幕下方的计时悬浮窗，打开仅含“取消计时”的操作菜单。选择该操作会放弃本次计时，不生成或保存记录。

## 交互

- 在悬浮窗主体上按住约 500ms，显示定位于悬浮窗上方的单项菜单。
- 短按保持既有行为：打开该计时的详情页。
- 菜单打开后，点击“取消计时”调用既有取消会话回调；点击菜单外部、开始新的短按或视图切换时关闭菜单。
- 在按住期间发生明显的指针移动时，取消长按，以避免滚动或拖动手势误触。

## 实现边界

仅修改 `src/components/TimerFloating.tsx`。复用从 `App` 传入并最终来自 `SessionContext` 的 `cancelSession`，不修改记录保存、会话持久化或同步逻辑。

## 验证

- 长按能打开菜单，短按仍打开计时详情。
- 菜单中的“取消计时”调用取消回调且不调用完成计时回调。
- 长按期间移动指针不会打开菜单。
- 运行 TypeScript/Vite 生产构建。
