# 待办快捷修改备注设计

## 目标

在待办快捷方式栏中增加“修改备注”，让用户无需进入完整详情页即可快速更新 `TodoItem.note`。

## 交互设计

- “移动分类”和“修改备注”位于同一行，各占一格。
- 点击“修改备注”后关闭后侧快捷方式栏，仅显示当前备注内容的多行输入框弹层。
- 按 Enter 或输入框失焦时保存；按 Shift+Enter 换行。保存内容会去除首尾空白，空内容清除备注。
- 点击“取消”退出编辑并恢复原备注，不触发保存；点击“确定”显式保存并退出。
- 点击标题后使用与备注一致的独立编辑弹层，避免快捷方式栏和移动端软键盘共同影响输入框定位。标题不允许保存为空。

## 数据流与测试

复用 `useTodoQuickActions` 的 `onSaveTodo` 回调，在 hook 中生成带更新 `note` 的待办对象并关闭编辑状态。备注编辑状态只从 `TodoItem.note` 初始化，更新也只写入该字段；日期字段必须原样保留。组件测试覆盖入口渲染、备注预填、保存字段隔离与回调 wiring；构建命令用于验证 TypeScript 与打包集成。
