# 单选堆叠图设计

## 目标

在单选统计来源中增加“堆叠图”，用于同时观察各选项在时间范围内的每日构成。该图表适用于活动自定义单选属性，也适用于分类统计中的二级标签来源。

## 设计

- 新增 `choiceStacked` 图表类型，加入单选属性和 `categoryActivity` 来源的可用图表列表。
- 横轴按本地日期，纵轴按卡片统计维度累计；“次数”统计每条记录，“时长”统计日志持续时间。
- 每个选项使用共享图表调色板，显示图例与日期刻度；没有数据时沿用共享空状态。
- 卡片编辑、卡片持久化、旧卡片兼容逻辑继续复用现有统计组件。

## 验证

补充图表能力与归一化测试，运行相关 Vitest 与 `npm run build`。
