# 分类级联归档设计

## 目标

为行动分类增加归档能力。归档分类时，其下所有标签同步归档；恢复分类时，其下所有标签同步恢复。

## 方案

在 `Category` 上增加可选的 `isArchived` 字段，缺失时按未归档处理。由分类上下文统一执行分类与标签的级联状态更新，分类详情页提供归档/恢复入口。

标签索引的活动区隐藏归档分类，归档区按分类展示分类及其归档标签。现有单标签归档行为保持不变；分类恢复按确认的产品语义恢复该分类下全部标签。

## 验证

补充归档工具测试，覆盖旧数据兼容、分类归档过滤以及分类/标签级联状态；运行 Vitest 相关测试与 `npm run build`。
