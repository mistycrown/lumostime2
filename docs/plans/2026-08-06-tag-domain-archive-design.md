# 标签与领域归档设计

## 目标

为标签（Activity）和领域（Scope）增加一致的归档能力：可从批量管理和详情页归档或恢复；索引页将归档项收纳到“已归档”分类；所有新建或编辑关联场景的选择器隐藏归档项，同时保留历史记录、统计和详情访问。

## 数据模型

`Activity` 增加可选字段 `isArchived?: boolean`，缺失值按 `false` 处理，以兼容已有数据。`Scope.isArchived` 沿用现有必填字段。归档只改变实体状态，不删除实体，也不修改已有日志、待办或规则中的关联 ID。

## 展示与操作

- 标签索引过滤活跃标签，并在底部按原分类展示归档标签。
- 领域索引过滤活跃领域，并在底部展示归档领域。
- 批量标签管理每个标签提供归档/恢复操作；领域管理沿用现有归档/恢复列表。
- 标签详情和领域详情标题区域提供归档/恢复操作，操作通过现有更新回调持久化。

## 选择器规则

在标签/领域选择器边界统一过滤 `isArchived !== true`。详情、统计、历史解析等读取完整数据，已存在的归档关联仍可显示。

## 验证

补充归档字段兼容、索引分组、选择器过滤和恢复操作的测试，执行 `npm run build`。
