# TODAY + PIN 4x2 小组件 A 系草稿设计

## 背景

用户希望新增一个桌面小组件，内容聚焦“今天的待办 + Pin 的待办”，并且可以直接从桌面开始计时；开始后按钮切换为停止按钮。当前阶段先不接入真实数据和原生 widget 渲染链路，而是先用 HTML + mock 数据探索版式。

## 设计结论

采用 `4x2` 宽版比例，信息组织为“单列合并清单”，而不是把 Today 与 Pin 拆成两个区块。

- 所有任务放在同一列中展示
- 用极轻量的 `TODAY` / `PIN` 标签区分来源
- 每行右侧提供一个可点击的 `START` / `STOP` 按钮
- 视觉方向统一为“极简印刷风”，通过留白、细线、版心、等宽小字来建立气质

## 草稿范围

本次只做 A 系三个布局草稿：

- `A1`：书页清单
- `A2`：横线账页
- `A3`：批注版心

三版共享相同 mock 数据与交互规则，只比较布局、密度、标签位置、分隔方式和印刷感强弱。

## 交互假设

- 同一时刻只允许一个任务处于计时中状态
- 点击 `START` 后，该行按钮切换为 `STOP`
- 再次点击 `STOP`，恢复到未计时状态
- 本阶段不接入真实倒计时，只用 mock 状态表达交互结果
- 任务区需要支持组件内部滚动，避免待办数量稍多时顶出圆角边框

## 交付形式

- 新增独立预览页：`public/mockups/widget-todo-pin-a-series.html`
- 页面内同时展示三张 `4x2` 比例草稿卡片，方便直接对比挑选
- 不修改现有 React 页面、Android widget provider 或原生渲染逻辑
