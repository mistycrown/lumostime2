# 主题方案快照完整性与资源恢复

## 目标

“保存当前配置为方案”必须覆盖全部主题配置，并且方案只保存资源引用。应用方案时，若所选字体或图片资源尚未同步到本地或已被删除，应用对应项目的默认值并向用户返回缺失提示，而不删除方案或素材目录记录。

## 方案

1. 将透明导航、自定义图表配色序列、UI 图标主题名称纳入主题快照。
2. 保留字体 ID 作为方案配置，不携带字体二进制文件。
3. 快照恢复后校验当前选中的主题资源：字体、页面背景、导航装饰与背景、导航图标、Memoir 背景、卡片背景、TimePal、UI 图标与成就瓶图标包。
4. 发现资源缺失时，仅将受影响的当前选择回退到对应默认值，并累积可读警告；素材目录与方案快照本身保持不变，等待云同步补全后可重新应用。

## 验证

新增测试覆盖：遗漏配置被捕获；缺失字体与活动图片资源产生警告并回退默认；未被选中的素材缺失不会影响当前方案应用。
