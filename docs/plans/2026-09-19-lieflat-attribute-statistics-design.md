# Lieflat 图型落地到自定义属性统计

## 状态

已确认，作为现有自定义属性统计卡片的第一阶段增量设计。

## 目标

- 将 Lieflat Charts 中适合当前数据契约的图型映射到现有属性统计卡片。
- 保留既有卡片配置和已有图表行为，新增能力采用稳定的语义类型标识。
- 避免把多选数据误表达为总和为 100% 的环形构成图。

## 第一阶段范围

- 数值属性保留分布、面积趋势、日历和概览图，移除箱线图以保持统计卡片聚焦。
- 数值属性新增 `numberCalendar`，按本年日期聚合，参考 `L17 Calendar Heat`。
- 单选属性保留 `choiceDonut`；多选属性不再提供环形图能力。
- 选项热力图在年度范围保留选项 × 日期矩阵；短周期改用按日构成网格，每天用分段条表达选项构成，避免 30 列矩阵和圆形渐变造成的拥挤。
- 选项分布采用普通横向条形图，同时支持次数与时长统计切换；切换只改变聚合口径、右侧数值和条形长度。
- 数值分布采用柱状图的分段横线柱样式：每个区间由多条横线叠成，顶部标注区间数量，参考 Lieflat 的编辑型图样。
- 数值趋势卡片不再提供；存量 `numberTrend` 配置读取时迁移为 `numberHistogram`。
- 既有面积趋势、直方图、KPI、条形图、词云继续兼容。

## 配色方案

- 配色以活动为作用域保存，所有统计卡片共享同一套颜色组，避免同一活动内不同图表各自使用独立颜色。
- 主题方案生成基于当前活动主题色的同色系深浅序列；莫兰迪与中华传统方案提供固定的多色序列，热力图按选项使用序列颜色，其他分类图按数据顺序取色。
- 配色选择器作为独立组件放入统计卡片管理面板，供后续其他可视化模块复用。

## 数据与渲染约束

- 存量 `numberBox` 配置读取时迁移为 `numberHistogram`，避免删除旧卡片后出现空白。
- `numberCalendar` 仅对本年范围显示，按本地日期聚合数值属性；其他时间范围继续使用现有趋势图。
- `choiceHeatmap` 只使用次数口径，按选项行、日期列保留每个单元格的实际值。
- 存量不合法的多选 `choiceDonut` 配置在读取时清洗为 `choiceBar`，避免破坏 Activity 加载。

- 现有组件文本与属性过滤测试继续通过；新卡片能力由统计卡片工具测试覆盖。
- 运行相关 Vitest 和 `npm run build`。
