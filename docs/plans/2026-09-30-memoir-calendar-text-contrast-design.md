# Memoir 日历文字对比度设计

## 目标

加深 Memoir 主日历中的星期字母和日期数字，同时保留清晰的视觉层级：星期字母最深，普通日期次之，今天的日期继续保持最深。

## 范围

- 仅修改 `src/components/MoodCalendar.tsx` 渲染的 Memoir 主日历。
- 星期字母从 `text-stone-400` 调整为 `text-stone-600`。
- 普通日期从 `text-stone-400` 调整为 `text-stone-500`。
- 今天继续使用现有的 `text-stone-900`，不改变其强调效果。
- 不修改桌面小组件、统计页面或其他日历视图。

## 实现方案

沿用现有 Tailwind `stone` 色阶，仅替换星期和普通日期的类名。这样改动集中、与当前 Memoir 视觉风格一致，并且不新增主题变量或额外样式层。

## 验收标准

1. 星期字母的颜色比普通日期数字更深。
2. 普通日期数字比修改前更深，但仍比星期字母浅。
3. 今天的日期仍使用现有最深颜色。
4. 其他日历与日历交互行为不变。
5. 项目生产构建成功。
