# 外观与 TimePal 设置同步设计

日期：2026-08-10

## 目标

将投喂功能提供的外观、TimePal 与样式偏好纳入统一 JSON 导出和云同步。所有自定义主题图片统一进入现有图片库、图片列表 JSON、云端图片清单与引用保护机制，避免恢复丢失或清理误删。

## 备份结构

新增可选 `appearanceData` 备份块，保存：

- 主题方案选择和自定义方案列表。
- 应用图标、UI 图标包、配色方案和自定义配色组。
- 当前背景、背景透明度、自定义背景元数据；当前导航装饰、自定义导航元数据与位置样式。
- TimePal 类型、自定义 TimePal 条目、点击切换、阶段阈值、标签限定、名言开关与内容。
- 仅内置字体选择。自定义字体标识在恢复时统一回退为默认内置字体。
- 日程图、日历数字、农历显示、时间轴、成就瓶等外观样式选择及配置。

旧备份不含 `appearanceData` 时保持本地外观设置不变。

## 图片资产

自定义背景、导航和 TimePal 图片使用 `imageService` 以稳定文件名写入统一图片库。其配置只保存文件名与展示元数据，而不保存设备相关的 Capacitor URL 或仅存在本机的私有目录路径。

首次读取旧的自定义背景或导航配置时，执行兼容迁移：读取旧 data URL 或本地私有文件，写入图片库，替换为图片文件名。恢复备份时，元数据和图片清单会一起参与云端/导入的图片恢复流程。

`settingsImageReferenceService` 统一收集 TimePal、背景和导航的图片文件名；图片清单重建、未引用检查、清理报告与实际清理都复用这一集合。因此主题图片会上传到云端，也不会被误判为未引用图片。

## 恢复与同步

`appearanceBackupService` 负责构建、校验与应用外观块。恢复会更新 localStorage、刷新背景与导航服务、广播外观变更事件，并让打开的界面读取新配置。主题或 TimePal 设置变化会更新时间戳并触发既有自动同步；手动同步模式则在下一次手动上传时写入。

自定义字体文件和元数据不导出。若备份记录的字体不是允许的内置字体，恢复为 `default`。

## 验证

- 外观块覆盖所列设置，且缺失字段的旧备份可正常恢复。
- 自定义字体恢复为默认内置字体。
- 自定义背景、导航、TimePal 图片写入统一图片清单，并被设置图片引用收集器保护。
- 图片列表重建和未引用检查不会列出仍被上述配置引用的图片。
- 云同步上传 payload、手动 JSON 导出和恢复流程包含 `appearanceData`。
- 运行针对性 Vitest 测试与生产构建。
