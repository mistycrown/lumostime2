# 日课周统计 XML 预览对齐设计

## 目标

修正系统组件选择器中的 4x3 与 4x4 静态 XML 预览，使其与已确认的运行时日课周表结构和坐标一致。

## 方案

- 4x3 预览按真实顺序排布：日期与刷新、唯一星期行、固定 31dp 日课行。
- 4x4 预览使用与运行时相同的 16dp 内容区，日期栏后紧跟星期行和日课行。
- 两份预览均用七列小方格表示周数据，并保持实际组件的左右留白与方格列起点。

## 验证

- 解析两个 drawable XML。
- 静态测试继续验证两个预览资源的尺寸和引用。
- 运行周统计测试、Web 构建和 Capacitor Android 同步；不执行 Android Gradle 编译。
