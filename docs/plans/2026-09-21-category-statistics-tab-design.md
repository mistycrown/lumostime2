# 分类统计 Tab 设计

## 目标

在分类详情页增加与标签详情一致的“统计” Tab。统计数据只取当前分类 `categoryId` 直接归属的可统计记录，统计来源限制为“标签时长”和“备注”。

## 方案

- 扩展共享 `ActivityAttributeStatistics`，支持限制可选统计来源；未传限制时保持标签详情现有行为。
- `Category` 增加可选的统计卡片与配色配置，复用现有数据持久化链路。
- 分类详情使用 `countableCatLogs` 传入共享组件，并以分类对象映射为统计宿主；首次使用时生成标签时长、备注两张默认卡片。
- 分类 Tab 顺序调整为“详情 / 时间线 / 统计 / 关联”。

## 数据与兼容性

新增字段均为可选字段，旧分类数据无需迁移。已有标签统计行为和卡片配置不变。

## 验证

补充共享组件来源限制的单元测试，运行相关 Vitest 与 `npm run build`。
