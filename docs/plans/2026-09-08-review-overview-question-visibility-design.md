# 回顾总览问题显示控制设计

## 目标

在回顾总览页右上角增加入口，进入独立的“回顾问题显示”设置页。用户可以按日课/回顾模板分组，对每一道问题单独控制是否出现在回顾总览中。

## 范围与行为

- 设置页按现有回顾模板分组展示问题，保留每日、每周、每月回顾的分组语义。
- 每道问题拥有独立开关，默认开启。
- 关闭问题只影响回顾总览的列表、问题/回答计数和问题详情入口。
- 不删除历史回答，不影响每日/每周/月回顾填写，也不修改回顾模板或模板快照。
- 历史模板快照中的问题优先使用其原始分组；没有稳定问题 ID 的旧数据使用问题文本作为兼容键。
- 关闭后，回顾总览中的空分组和空周期不展示；重新开启后历史答案立即恢复。

## 数据与状态

- 在 `ReviewContext` 增加 `reviewOverviewQuestionVisibility` 和更新函数，作为轻量本地设置持久化。
- 持久化值使用问题键到布尔值的映射，未出现的键视为显示。
- 优先键格式为 `kind:questionId`，旧记录没有 ID 时使用 `kind:normalizedQuestionText`，必要时附加分组键避免同名问题冲突。
- 总览构建工具接收可选的可见性过滤器，在分组、问题数、回答数和详情数据生成前过滤。

## 页面与导航

- `ReviewOverviewView` 顶部右侧增加设置图标按钮和可访问性标签。
- 新增独立的 `ReviewOverviewQuestionVisibilityView` 全屏子页，复用设置子页的返回与硬件返回模式。
- 新页面按模板组列出问题；每行展示问题标题、题型标签和原生 checkbox/toggle 控件。
- 题型标签只用于识别，不提供批量题型开关；每个问题单独变更并立即保存。
- 从回顾总览进入设置页，再返回时保留总览状态；设置变化后总览重新计算计数和列表。

## 兼容性与边界

- 新增设置键不参与回顾数据仓库同步，避免显示偏好覆盖历史数据。
- 模板被删除或当前没有回答的问题仍可从当前模板显示控制页访问；历史快照无法再定位的问题列入“未分组/历史问题”。
- 重置应用设置时清理该显示偏好；导入回顾数据不覆盖当前显示偏好。

## 验证

- 为可见性过滤和问题键生成增加单元测试：默认显示、单题隐藏、分组计数更新、同名问题隔离、无 ID 旧数据兼容。
- 运行相关 Vitest 测试。
- 运行 `npm run build` 并手动检查回顾总览、设置页、返回路径和深色模式下的开关可读性。
