# Memoir 回顾节点继承自定义时间线样式

## 目标

当用户启用非默认时间线样式时，Memoir 中的日、周、月回顾节点与普通日志节点使用同一套图标、颜色、大小与角度。默认时间线样式保持现有的日/周/月彩色圆点不变。

## 现状

`TimelineItem` 已通过 `TimelineStyleRail` 为普通日志渲染自定义时间线节点。回顾条目在该分支中额外传入 `forceDotNode` 和固定颜色覆盖，导致自定义样式下仍显示为紫、黄、粉圆点。

## 方案

仅在 `TimelineItem` 的非默认时间线分支移除回顾条目的圆点强制与颜色覆盖，让所有条目统一由当前 `TimelineStyleRail` 配置渲染。

- 非默认样式：日/周/月回顾与普通日志继承同一时间线主题、节点色、图标大小和角度。
- 默认样式：继续使用原有按回顾类型区分的紫、黄、粉圆点。
- 不修改回顾卡片内容、点击行为、时间线连线或设置数据结构。

## 验证

为节点渲染分支补充回归测试，覆盖默认样式保留固定彩色圆点，以及自定义样式的回顾节点不再传递覆盖参数；运行 `npm run build`。
