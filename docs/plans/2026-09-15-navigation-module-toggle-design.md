# 导航模块开关设计

## 目标

在偏好设置中提供一个“导航模块开关”条目，使用一行五个复选框分别控制底部导航中的记录、待办、脉络、档案和索引模块是否显示。

## 方案

- 在 `SettingsContext` 中增加导航模块可见性状态，默认五项全部启用，并通过 localStorage 持久化。
- 在 `PreferencesSettingsView` 的通用偏好区域增加横向复选框组，沿用现有设置页的间距、边框和字体风格。
- `BottomNavigation` 根据可见性状态过滤导航项；点击索引时继续沿用默认索引页逻辑。
- 当没有任何模块可见时不强制跳转，导航栏自然隐藏；恢复任一模块后立即显示。

## 验证

- TypeScript/Vite 生产构建。
- 检查默认状态、刷新后持久化状态以及导航栏过滤结果。
