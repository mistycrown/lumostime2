# 快捷方式栏小组件设计

日期：2026-04-18

## 目标

新增一种 `4x1` 的“快捷方式栏”桌面小组件，允许用户在模板中配置 4 个应用内快捷入口，并复用现有小组件模板管理、桌面标题切换、Android 原生渲染与点击回传体系。

## 一期范围

- 新增第三种小组件类型：`shortcut`
- 仅开放 `4x1` 尺寸
- 每个槽位可配置一个快捷动作
- 支持动作：
  - 打开添加补记
  - 快速打点
  - 跳转到今天的 Review
  - 打开搜索
  - 打开画廊
- 点击标题时，在同尺寸模板之间循环切换，允许跨类型切换

## 配置体验

- 在小组件设置页新增 `快捷方式栏` tab
- 用户先创建模板，再配置 4 个槽位
- 每个槽位只保留两项配置：
  - 快捷动作
  - 可选自定义显示名称
- 不提供自定义图标和强调色

## 视觉设计

- 快捷方式栏采用与计时器/日课不同的视觉语言
- 使用类 Lucide 风格的线性图标
- 使用浅灰色圆角方形背景
- 桌面 widget 上以图标为主
- 设置页预览中显示图标和短标签

## 技术方案

### 共享数据层

- `WidgetType` 扩展为 `timer | daily | shortcut`
- 槽位结构新增 `shortcutAction`
- 快捷方式槽位复用现有 `label` 作为显示文案
- 通过共享 service 维护动作元数据与默认文案

### React 侧

- 设置页增加 `shortcut` 模板管理与槽位配置弹窗
- 应用内新增 widget shortcut 动作分发：
  - 打开补记
  - 快速打点
  - 今日 Review
  - 搜索
  - 画廊
- 深链入口统一为 `lumostime://widget?action=...`

### Android 侧

- 新增 `ShortcutWidget4x1` provider 和对应 `appwidget-provider` 配置
- 原生模板绑定从“按类型+尺寸”切换为“按尺寸绑定当前模板”，以支持同尺寸跨类型循环
- slot 点击时根据当前绑定模板类型动态分发：
  - `timer` 继续走计时逻辑
  - `daily` 继续走日课逻辑
  - `shortcut` 直接拉起应用深链
- bitmap 渲染为新的浅灰方形快捷入口样式

## 风险与约束

- 现有 4x1 provider 将支持循环到其他类型模板，因此绑定逻辑需要从 provider 类型解耦
- 快捷动作统一采用“打开 App 后执行”，一期不做后台无感执行
- Android 原生图标使用 Canvas 绘制近似 Lucide 风格，不依赖 React 图标库

## 验证

- 设置页能创建和保存 `shortcut 4x1` 模板
- Android 桌面能添加 `shortcut 4x1` 小组件
- 点击 slot 可正确拉起 App 并执行对应动作
- 点击标题可切换到同尺寸的 timer / daily / shortcut 模板
- `npm run build` 通过
