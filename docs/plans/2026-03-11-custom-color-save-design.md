# 自定义颜色色值保存逻辑补全设计
日期：2026-03-11

## 目标
补全“输入自定义颜色 HEX 并保存”的最小闭环，先保证保存逻辑完整可靠，不扩展到其他颜色选择器的使用链路。

## 范围
- 统一自定义颜色输入的 HEX 规则，支持 `#ABC`、`#AABBCC`、`#AABBCCDD` 及无 `#` 写法。
- 保存前归一化为大写 HEX。
- 阻止重复保存。
- 读取旧数据时自动清洗无效值、重复值和缺失字段。
- 组件层补充输入预览、回车提交、空值/无效值/重复值提示。

## 方案
1. 在 `customColorGroupService` 中集中实现 HEX 归一化与脏数据清洗。
2. `CustomColorGroupManager` 只消费服务层规则，不再维护另一套校验逻辑。
3. 保存成功后立即刷新列表并清空输入；重新进入页面时从持久化结果恢复。

## 验证
- 手动输入合法/非法/重复色值。
- 校验点击添加与回车提交行为一致。
- 重新加载页面后颜色列表保持一致。
- 执行构建，确认无类型或打包错误。
