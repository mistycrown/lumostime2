# 场景组手动排序设计

## 背景

“场景设置 -> 切换模式管理”里的手动模式目前只能选择“当前展示组”，不能调整多个场景组的顺序。用户希望在手动模式下直接管理这些组的先后，并且这个顺序要同步影响场景页右上角的手动快速切换下拉列表。

## 目标

- 在手动模式管理区增加场景组上移 / 下移能力。
- 不新增额外排序字段，直接以 `sceneGroupState.groups` 的数组顺序作为唯一顺序来源。
- 让设置页中的手动模式选择器、场景页右上角的快速切换菜单都读取同一份顺序。

## 方案

1. 在 `src/utils/sceneGroupStorage.ts` 增加 `moveSceneGroup` 纯函数。
2. `SceneSettingsView` 在手动模式区新增“场景组顺序”列表，每行提供 `上移 / 下移` 按钮。
3. 触发排序后立即走现有 `persistSceneGroupState` 保存流程，复用 `sceneGroupsUpdated` / `sceneTimeSlotsUpdated` 事件广播。
4. `SceneView` 不单独维护顺序逻辑，继续直接遍历 `sceneGroupState.groups`，因此右上角快速切换菜单会天然跟随设置页顺序。

## 影响

- 手动模式下的展示组选择顺序会改变。
- 场景页右上角的手动切换下拉顺序会同步改变。
- 自动模式下命中规则时，本仓库现有“按 `groups` 顺序取第一个命中组”的逻辑也会受到组顺序影响，这保持现有实现的一致性，不额外拆分第二套优先级。

## 验证

- 单元测试覆盖 `moveSceneGroup` 的上移、下移和越界不移动行为。
- 手动检查设置页中排序后，场景页右上角手动切换列表顺序是否同步更新。
