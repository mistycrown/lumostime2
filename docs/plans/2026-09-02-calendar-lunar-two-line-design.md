# 月视图农历两行显示设计

## 目标

统一待办月视图日期格中的农历标签，使每个农历标签固定占两行，逐字纵向显示。例如“初四”显示为“初”在第一行、“四”在第二行；“廿三”同样按字符逐行排列。

## 范围

- 仅调整 `src/components/TodoMonthView.tsx` 日期头部的农历渲染。
- 保留现有农历开关、农历计算逻辑、公历日期按钮和其他日历视图行为。

## 方案

将 `getCalendarLunarLabel(day)` 的结果拆分为字符数组，在固定宽度和固定两行高度的纵向 flex 容器中渲染。容器继续位于公历日期右侧；农历关闭或没有标签时不渲染该容器。通过固定尺寸避免“初四”等短标签单行显示，也避免换行导致日期头部高度漂移。

## 验证

- 运行 `npm run build`。
- 检查农历显示开启时，短标签和长标签都各占两行，农历关闭时日期头部不留额外空白。
