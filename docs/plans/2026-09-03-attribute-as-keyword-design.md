# 属性作为关键字设计

## 目标

允许每个标签选择一个单选或多选属性作为关键字来源。记录勾选该属性的选项后，即使备注没有对应文字，也能在标签详情的关键字日历中命中。

## 设置规则

- “属性作为关键字”复选框放在每个未归档的单选、多选属性设置中。
- 每个标签最多启用一个属性；启用新属性时自动关闭原属性。
- 归档作为关键字来源的属性时同步关闭该设置。

## 匹配规则

- 关键字日历使用标签原有关键字与来源属性的未归档选项名称，按名称去重。
- 记录标题或备注包含任一关键字时，沿用原有命中逻辑。
- 记录保存了来源属性的选项 ID 时，对应选项名称也视为命中。
- 属性选项匹配在展示时动态计算，因此历史记录立即生效，无需迁移或修改备注。

## 兼容性

`isKeywordSource` 是属性定义上的可选字段，旧数据缺省为关闭。原有备注关键字和属性关键字可同时显示；名称相同时只展示一次。

## 验证

增加纯函数测试，覆盖单选、多选、历史记录、归档选项、备注共存和重名去重，并运行生产构建。
