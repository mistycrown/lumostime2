# 脉络待办右栏透明度设计

## 目标

让脉络分栏布局的右侧待办栏明显透出底图，同时保持待办文本、复选框与交互状态清晰可辨。

## 方案

将 `TimelineTodoSidebar` 的浅色与深色背景不透明度由 95% 降至约 75%。保留既有的轻度毛玻璃和阴影，避免底图细节直接干扰内容阅读。

## 取舍

- 仅降低不透明度会让底图更清楚，但在纹理复杂的主题下可读性不稳定。
- 降低不透明度并保留毛玻璃可维持“明显透出”和内容清晰之间的平衡。
- 本次不改变右栏尺寸、分隔线、按钮或数据逻辑。

## 验证

构建生产包，确认 TypeScript 与样式编译通过；在脉络分栏布局下确认浅色和深色主题的右栏均可透出底图。
