# 脉络并行时间块与当前线设计

## 目标

使“时间轴 + 待办”布局准确表达排期类型与并行记录，并让今天的时间定位、主题和冻结回顾行为一致。

## 待办侧栏

- 任务行只显示排期类型前导符号与任务名称，不显示分类或日期副文本。
- 类型判定复用排期页面的共享优先级：Complete、Do/截止、Arrange、Repeat、Maybe。
- 日课分组与现有手动、自动、次数状态保持不变。

## 时间轴

- 使用区间分栏算法处理日志：重叠区间组成一个组，组内任务分配到最早可用列，按总列数平分宽度。
- 仅当选择今天时渲染当前时间线。颜色取主题色；没有主题色时使用黑色；夜间模式使用白色。
- 进入脉络页时优先将当前时间滚动至视口，历史日期维持内容顶部位置。
- Daily / Weekly / Monthly 回顾卡放回时间轴滚动区域之外，作为日历下方的冻结区。
- 缩放按钮继续位于 24:00 后方的内容末尾，随时间轴内容滚动。

## 设置清理

移除“时间轴默认定位”下拉项、对应 SettingsContext 状态、验证工具和 localStorage 键；不再使用固定 08:00 初始刻度。

## 验证

1. 两条及以上重叠日志并列显示，非重叠日志保持完整宽度。
2. 今天显示主题/黑/白当前线，历史日期不显示。
3. 进入今天自动滚到当前刻度；回顾卡保持在时间轴上方。
4. 侧栏任务只有类型前导符号与名称。
5. 生产构建与相关测试通过。
