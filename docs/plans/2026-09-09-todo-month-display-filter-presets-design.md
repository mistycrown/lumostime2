# Todo 月视图显示筛选预设

## 背景

Todo 月视图已有一个使用自定义筛选表达式的“隐藏筛选式”。需要增加显示筛选预设，让用户保存多个表达式并快速切换，同时保证隐藏筛选和显示筛选不会同时作用。

## 设计

- 仅作用于应用内 Todo 月视图，不影响周视图、列表视图、桌面月历或全局筛选器。
- 增加互斥筛选模式：不筛选、隐藏筛选、显示筛选。
- 隐藏筛选保留当前表达式；显示筛选从月视图专属预设中选择一个表达式。
- 预设保存名称和筛选表达式，支持新建、编辑、删除。删除当前预设后回退到不筛选。
- 模式、预设列表和当前预设 ID 使用本地存储，沿用现有隐藏筛选的持久化边界。
- 过滤执行统一复用 `matchesTodoFilterExpression`，显示模式保留匹配项，隐藏模式排除匹配项。

## 交互

月视图设置弹层顶部提供筛选模式切换。隐藏模式显示现有表达式编辑器；显示模式显示预设下拉切换器、编辑/删除操作和新建入口。新建或编辑时要求名称与表达式均非空，保存后自动选中新建或更新的预设。

## 验证

- 为筛选状态计算增加纯函数测试，覆盖隐藏、显示、无筛选和互斥行为。
- 运行相关 Vitest 测试与 `npm run build`。
