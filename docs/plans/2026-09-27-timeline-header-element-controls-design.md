# 时间线顶部主题元素调试设计

## 目标

让时间线顶部主题的所有视觉元素都能在调试面板中独立调整，同时保持日历功能和既有主题存档兼容。

## 调整模型

- 顶部背景、日期栏背景、选中日期背景：横向缩放、纵向缩放、透明度。
- 贴纸：横向位置、纵向位置、等比大小、透明度。
- 顶部按钮颜色：工具栏图标、文字、边框以及折叠日期栏内的星期、日期、圆点共用同一颜色。

背景和贴纸的透明度均作为素材默认透明度的乘数，因而保留每套主题原有的层次关系。缩放范围限定为 50%–200%，透明度限定为 0%–100%，贴纸坐标范围限定为 -200px–200px。

## 数据与兼容性

每套主题保存一份 `TimelineHeaderThemeAdjustments`。新增字段都有默认值；读取旧版存档时自动使用默认缩放与透明度，因此旧的贴纸位置、日期栏缩放与按钮颜色都会保留。

## 调试面板

面板导航依次呈现三层背景、按钮颜色与全部贴纸。各元素只显示对它有效的调整项；重置当前元素只重置该元素，全部重置恢复该主题的默认视觉参数。所有操作继续实时预览，只有点击“保存调整”才写入设置。

## 验证

- 对现有粉色手账和小王子主题分别加载、切换、展开/收起日历。
- 确认日期栏文字随按钮颜色实时变动。
- 运行 `npm run build`。
