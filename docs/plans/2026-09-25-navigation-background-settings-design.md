# 新版导航栏背景设置设计

## 目标

在“投喂小鱼干 → 导航栏”中增加“使用新版导航设置”开关。开关关闭时保持现有导航装饰功能；开启时将图片作为底部导航栏自身的背景，并提供内置背景、自定义上传、选择、删除以及位置/缩放/透明度调整。

## 方案

沿用现有导航装饰服务与调整器的实现思路，但为新版背景使用独立配置和事件：

- `navigation_new_mode_enabled` 保存开关，默认 `false`。
- 新版背景列表、当前背景和调整参数使用独立 key，避免覆盖旧版前景贴图配置。
- 首个内置资源使用 `/dchhnew/1.webp`；`1.png` 作为同名资源的加载失败回退。
- 上传图片沿用现有 `imageService`/Capacitor 文件持久化能力。
- 复用已有调整器的 X/Y、缩放、透明度控件与实时预览行为，新增模式参数以更新新版背景状态。

## 渲染行为

- 旧版模式：保留现有前景装饰层和旧版调试器行为。
- 新版模式：把当前图片设置为 `<nav>` 的 `backgroundImage`，背景重复、位置、尺寸和透明度由新版配置控制；不再渲染前景装饰层。
- 导航项文字与交互层级保持不变。

## 验证

- `npm run build`
- 手动检查开关切换、内置 WebP 加载、上传/删除、调整实时预览与刷新后持久化。
