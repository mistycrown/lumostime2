# 外部导航资源与兔子云朵主题包更新设计

日期：2026-09-28

## 目标

移除应用新版导航中的内置图片背景和粉色图标资源，使导航视觉素材仅来自用户本地添加或导入主题包；同时发布调整后的“兔子云朵”主题包 1.0.1。

## 应用导航

- 删除内置导航背景 `new-default` 与其 `/dchhnew/1.webp` 资源引用。
- 保留非资源的“无背景”选项、本地添加入口、已导入主题包资源和用户自定义图标方案。
- 删除内置粉色图标模式及其 `/dchhicon/pink/*` 资源引用；图标选择保留文字模式和自定义方案。
- 对旧存储中的 `new-default` 和 `pink` 选择进行无损回退，分别恢复至无背景和文字导航；不删除任何用户或主题包导入的素材。
- 旧版前景导航装饰不在本次范围内。

## 主题包

- 将包版本提升为 `1.0.1`，UIIcon 使用 `cat`，配色使用 `morandi-pink`。
- 使用内置 Candy 成就瓶图标与 `blushBloom` 瓶身，时间线使用 `celestial`。
- 将 `assets/fonts/乐米小熊日记体.ttf` 作为包内字体；Memoir 背景透明度设为 0.7，导航背景透明度设为 0.8。
- 包目录重命名为“兔子云朵主题包”，发布文件命名为 `rabbit-clouds-theme-v1.0.1.zip`，ZIP 根目录仅含 `theme.json` 与 `assets/`。

## 验证

- 为导航回退添加或更新服务测试，并运行相关 Vitest 测试和生产构建。
- 检查主题包 JSON、资源引用、ZIP 根目录和应用解析器导入结果。
