# 节点帮助、脉络快捷方式与返回导航设计

## 目标

- 在备注 `[[ ]]` 快捷按钮旁提供完整的节点使用说明。
- 将节点目录加入“偏好设置 → 脉络页顶部快捷按钮”的可配置动作。
- 统一节点目录、节点详情、节点管理页从软件按钮和 Android 硬件返回键的返回路径。

## 设计

### 帮助提示

复用 `FeatureHint`，使用稳定的节点帮助 ID。说明覆盖节点入口、在备注中创建节点、全角括号、别名、节点详情中的历史记录/反向链接/相关节点、节点目录搜索与分类管理等场景。提示仍支持“好的”和“不再显示”，不改变现有 `[[]]` 插入逻辑。

### 脉络快捷方式

新增 `nodes` 时间脉络快捷动作，加入统一的动作选项、偏好设置排序/增删列表、脉络顶部按钮和“更多”菜单。动作打开设置的节点子页，并标记为快捷方式来源，使返回时关闭设置覆盖层并回到脉络页。

### 返回导航

节点目录保持在设置子页中：普通设置入口返回设置主页，脉络快捷入口返回脉络页。节点详情继续作为全局覆盖层，节点之间的前进/后退由 `NodeContext` 历史处理；详情层关闭后交还底层页面。Android 硬件返回优先交给节点详情/节点管理的注册处理器，再按设置子页来源状态关闭或回到对应的主页面。

## 验证

- 构建 TypeScript/Vite 产物。
- 覆盖快捷动作选项和节点详情返回来源的单元测试或静态回归检查。
- 手动检查备注按钮、节点目录、节点详情、节点管理在 Web/Android 返回顺序。
