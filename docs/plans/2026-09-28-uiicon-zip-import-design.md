# UIIcon ZIP 导入设计

## 目标

允许用户从设置页导入一套 UI 图标 ZIP，并作为可选 UI 主题立即使用。

## ZIP 约定与校验

- 仅接受 PNG、WebP 格式的图片。
- 文件可位于 ZIP 的任意子目录。
- 图片基础文件名必须为 `01` 至 `96`。
- 每个编号必须且只能出现一次；缺号、重号或其他图片都会使整个导入失败。

## 导入流程

解析成功后，以 ZIP 文件名（去除 `.zip`）作为主题名。若同名主题已存在，弹出覆盖、追加、取消选择：覆盖替换主题并回收旧资源；追加创建 `名称 (2)` 等唯一名称；取消不写入资源。写入过程中若有失败，删除本次已保存资源。成功后刷新主题列表并自动切换到新主题。

## 展示与验证

自定义主题与内置主题显示在同一网格，预览编号 `01` 至 `04`。为 ZIP 解析服务添加单元测试，覆盖完整包、缺号、重号、无效格式和子目录排序；最终运行生产构建。
