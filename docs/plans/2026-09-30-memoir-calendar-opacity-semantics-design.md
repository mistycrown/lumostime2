# Memoir 日历背景透明度语义统一设计

## 目标

让 Memoir 日历背景的“图片透明度”与卡片背景使用相同语义：背景图片本身保持完整渲染，透明度数值通过白色蒙版强度控制图片的明显程度。

## 现状与根因

卡片背景使用 `1 - opacity` 作为白色蒙版的不透明度；数值越低，白色蒙版越强，图片越不明显。Memoir 日历目前直接把设置值写入图片元素的 `opacity`，数值降低时图片层直接透明并露出页面底图，因此与卡片背景的视觉和语义不同。

## 实现

- Memoir 日历背景图片始终以完整不透明度渲染。
- 在图片上方增加覆盖整个日历的白色蒙版，蒙版不透明度为 `1 - 图片透明度`。
- 对输入值执行 `0` 到 `1` 的限制；无效值沿用当前默认值 `1`。
- 保留现有图片裁切、圆角、阴影、背景选择、持久化、主题包配置及快捷按钮联动。
- 未选择背景图片时继续使用原有 `bg-stone-50` 外观。

## 验证

- 透明度 `0` 对应白色蒙版 `1`。
- 透明度 `0.25` 对应白色蒙版 `0.75`。
- 透明度 `1` 对应白色蒙版 `0`。
- 超出范围和非有限数值被安全归一化。
- 运行相关 Vitest 测试与 `npm run build`。
