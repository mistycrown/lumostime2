# 主题包资源保留与重复导入设计

日期：2026-09-28

## 目标

主题包删除时让用户决定是否一并删除其资源；选择保留时，资源应脱离主题包后继续可用。随后导入相同主题包 ID 时，用户可选择覆盖这些保留资源或让新旧资源并存。

## 删除流程

- 删除主题卡片仍会在主题激活时先切换到默认主题。
- 包来源主题显示资源处理确认：取消、仅删除主题并保留资源、删除主题及资源。
- 保留时，把包资源迁移为带保留来源标识的用户资源，更新贴纸分组、导航选择、时间小友、卡片背景和当前选择等内部引用；图片与字体不删除。
- 删除资源时沿用完整清理逻辑，删除包记录、资源配置、图片和包内字体。

## 重复导入

- 为保留资源记录原主题包 ID、资源映射和来源版本。
- 导入 ZIP 解析出已有同 ID 的保留资源时，先显示选择：取消、覆盖旧资源、保留旧资源。
- 覆盖删除对应保留资源后正常导入；保留旧资源则为新导入资源分配新的主题实例命名空间，确保两套资源可同时选择和使用。
- 正常已安装主题的同 ID 更新仍保持现有的直接替换逻辑。

## 验证

- 覆盖删除、保留资源、同 ID 覆盖、同 ID 并存均通过服务测试。
- 验证当前选择和贴纸/导航/卡片背景等引用在迁移后继续有效。
