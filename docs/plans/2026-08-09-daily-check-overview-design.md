# 日课总览设计

## 背景

新增一个独立的“日课总览”顶层页面，用于集中查看按日课模板分组的日课进度，并进入单个日课的统计详情。页面参考给定的总览列表和详情页视觉方向，但暂不实现标题栏日期日历、底部导航，以及详情页中的概览/日历图/热力图/趋势/记录分页。

## 目标

- 在“设置 > 内容”中提供“日课总览”入口。
- 在“偏好设置 > 脉络页顶部快捷按钮”中提供“日课总览”快捷动作。
- 总览页支持手动布尔值、手动数字、自动时长三种日课类型。
- 手动布尔值支持直接切换今日状态。
- 手动数字支持直接修改今日数值。
- 自动时长只读，使用现有自动日课筛选逻辑和时间记录计算。
- 点击日课进入对应类型的统计详情页。
- 复用现有 `dailyReviews`、`checkTemplates`、`logs` 和日课工具，不新增持久化数据结构。

## 方案

### 导航

- 在 `AppView` 中新增 `DAILY_CHECKS`。
- 在 `AppRoutes` 中渲染日课总览页。
- 使用现有 `NavigationContext` 的主视图切换和返回机制。
- 从设置页入口进入时关闭设置层；从脉络页快捷动作进入时直接切换到日课总览。
- 日课总览内部维护选中的详情条目，详情返回总览；总览返回进入前的主页面，缺少来源时默认返回脉络页。

### 数据流

- 以启用且 `isDaily` 的 `CheckTemplate` 为分组来源。
- 以 `dailyReviews[].checkItems` 作为日期快照和手动状态来源。
- 当前日期没有快照时，列表使用模板默认值；首次执行手动操作时通过 `ensureDailyReviewForDate` 创建并写入快照。
- 自动日课使用 `updateAutoCheckItems` 按当前日志和筛选上下文实时计算。
- 手动操作复用 `applyDailyCheckActionForDate`，保持与每日回顾、脉络侧栏、NFC 和小组件一致。

### 总览页

- 采用浅色纸张背景、细分割线、紧凑分组和克制的彩色圆形图标。
- 每个分组显示标题和完成数量。
- 每条日课显示标题、类型占位副标题、今日值和近期状态点。
- 布尔值右侧显示完成状态。
- 数字右侧只显示数字，不显示单位。
- 时长右侧显示格式化的时长。
- 点击条目进入详情；点击手动操作控件时阻止打开详情。

### 图标

- 不修改日课模板中保存的 emoji 或图片字段。
- 日课页面使用 Lucide 图标和稳定的语义映射，以纯色图标替代原始 emoji/图片呈现。
- 关键词映射覆盖阅读、学习、运动、心情、冥想、饮水等常见语义；无法匹配时按日课类型回退到布尔值、数字或时长图标。
- 使用绿色、蓝色、紫色、红色、金色等互不混淆的轻量色彩，避免单一色相占满页面。

### 详情页

总览和详情使用同一页面级组件，但按日课类型渲染三个独立的统计变体：

- 布尔值：今日状态、最近 7 天完成率、连续完成天数、最近状态点。
- 数字：今日数值/目标、最近 7 天平均值、达标天数、最近数值条形记录。
- 时长：今日时长、筛选目标/达成比例、本周累计、平均日时长、达标天数、最近时长条形记录。

详情页只做单页内容，不实现参考图中多标签页切换。

## 边界和异常处理

- 禁止手动修改自动时长日课。
- 找不到已点击日课时不写入数据，并显示轻量提示。
- 旧数据缺少 `manualMode`、`targetCount`、图标或日课快照时，沿用现有归一化和模板默认值。
- 模板被禁用或条目被禁用后，不在总览页显示。
- 日课数量为零时显示简洁空状态，并引导用户前往日课模板设置。

## 测试与验证

- 为统计辅助函数增加布尔值、数字、时长的边界测试。
- 为页面增加手动切换、数字输入、自动时长只读和详情跳转测试。
- 执行 `npm run build`。
