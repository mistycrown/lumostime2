# 时间轴相邻记录布局设计

## 目标

当一条时间轴记录的结束分钟等于下一条记录的开始分钟时，让两条记录在同一条视觉轨道上连续衔接，避免因列重新分配产生交错错位。

## 方案

扩展 `layoutParallelScheduleBlocks` 的分组边界判断：记录之间存在重叠时继续使用并行列；没有活动列时，只有下一条记录开始时间不等于当前分组的最晚结束时间，才结束当前分组。这样首尾相接的记录会复用释放的列，同时仍保持真正独立时间段的列宽计算互不影响。

## 验证

增加相邻记录回归测试，确认两条首尾相接记录都使用第 0 列且列数为 1；保留现有重叠和普通相邻时间段测试，确保并行布局行为不变。
