# 脉络待办栏日课设计

## 目标

在“时间轴 + 待办”工作区的右列提供置顶、今天和日课三个分组。侧栏开合状态跨会话保存；时间轴的缩放工具不再悬浮在顶部。

## 数据与状态

- 用独立的本地存储键保存待办列是否收起，默认展开。
- 日课直接使用选中日期的 `DailyReview.checkItems`，不维护边栏副本。
- 若手动日课首次点击时当天没有 `DailyReview`，根据启用的日课模板创建 Daily Review、导入日课项目，再将点击写入该项目。
- 每次进入脉络页，对当天已存在 Daily Review 的自动日课调用既有自动计算器。自动日课只展示计算结果，不接受边栏手动修改。

## 交互

- 普通手动日课点击切换完成与未完成。
- 次数型日课每次点击加一；达到目标后显示已完成和次数。再次点击按 Daily Review 既有逻辑重置计数。
- 侧栏去掉“今日待办”总标题，仅保留“置顶”、“今天”、“日课”分组标题。
- 时间轴使用细滚动条；缩放加减按钮放在时间内容底部，跟随滚动内容，不固定在视口。

## 验证

1. 刷新页面后侧栏维持上一次展开或收起状态。
2. 没有 Daily Review 时，第一次点击手动日课会创建当天 Review 并立即反映状态。
3. 自动日课在进入脉络页后按最新记录重新计算。
4. 次数型日课可递增、完成并在再次点击后重置。
5. 侧栏和时间轴在生产构建中可正常滚动。
