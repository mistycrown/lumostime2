# 脉络重叠时间块列宽修复设计

## 目标

脉络左右分栏布局中，只有存在有效时间重叠的时间块才共享多列宽度。重叠组结束后，即使下一块与上一块紧邻，也应恢复为单列满宽，避免右侧没有计划时内容仍被限制在左半列。

## 方案

继续使用现有的贪心列分配和 1 分钟边界容差。每当活动时间块集合为空时，立即结束当前布局组并为该组写入 `columnCount`；下一块从第 0 列开始计算。这样保留重叠块的并行列分配，也让真正没有同时段块的后续记录独立使用完整宽度。

## 验证

- 保留已有的重叠列分配、列复用和相邻边界测试。
- 新增“重叠组结束后紧邻的时间块恢复单列满宽”回归测试。
- 运行 `npx vitest run src/components/TimelineScheduleCanvas.test.ts` 和 `npm run build`。
