# 脉络计划拖拽与时间编辑设计

## 目标

在脉络时间轴中支持将待办安排为计划，并允许用户快速调整时间块的起止边界。

## 基础修复

- 修正分栏拖动清理逻辑：会话为空时不读取 `timerId`。
- 在 00:00 前加入 12px 画布留白，刻度、记录、当前时间线和初始定位统一使用该偏移。

## 计划记录

- 扩展 `Log` 增加可选 `isPlanned` 标记。
- 待办拖到当前选中日期的时间轴时，以落点创建默认 30 分钟的计划记录，关联 `linkedTodoId`。
- 使用虚拟计划类别和活动 ID，避免写入用户活动分类或参与实际活动统计。
- 计划块使用主题色虚线轮廓、`计划`标签和较轻背景，与真实记录区分。

## 交互

- 待办采用 Pointer 拖拽；点击未移动时仍进入既有快捷编辑。
- 时间块长按后进入边界编辑，展示上下拖拽柄，起止时间按 5 分钟吸附。
- 新计划创建后自动进入边界编辑；用户在画布其他位置点击或失焦时退出编辑。后续再次长按才可调整。
- 普通点击时间块继续打开既有完整编辑入口。

## 验证

- 为时间块位置偏移和计划记录时间计算补充单测。
- 运行相关 Vitest 测试和 `npm run build`。
