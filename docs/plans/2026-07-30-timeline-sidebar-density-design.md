# 脉络待办侧栏密度设计

## 目标

让脉络页的待办侧栏与排期页使用同一套当日任务语义，并收紧日课与回顾入口的视觉密度。

## 待办

- 读取排期页当天可见的 Arrange、Due、Repeat、Maybe 与 Complete 项，排除 Trace。
- 同一“待办”分组内混排未完成和当天完成项，沿用排期工具的优先级。
- 每行左侧使用空心状态圆圈；完成时以主题色描边和勾号表示，默认主题色为黑色，不填充背景。
- 标题保持单行截断；右侧显示短排期标签 `ARR`、`DUE`、`REP`、`MAY` 或 `DONE`。

## 日课与回顾

- 当前日期早于今天时不显示日课分组，也不显示其占位状态。
- 日课项压缩为单行：手动项使用圆圈勾选，自动项使用方框勾选，次数项使用方框数字。
- 回顾入口与侧栏内边距、分组标题对齐，采用低高度工具条，避免形成独立卡片。

## 验证

- 为当天待办筛选补充单元测试，覆盖完成项保留与 Trace 排除。
- 运行相关 Vitest 测试和 `npm run build`。
