# 日课周统计密度与宽度修正设计

## 问题

- 4x4 将所有可用高度平均分给日课行，日课较少时行间空白过大。
- 4x4 与 4x3 的七日格起点偏右，标题与打卡区域之间存在不必要空隙，右侧内边距也偏大。
- 4x3 使用完整组件宽度生成行位图，再被带左右内边距的列表横向缩放，导致文字被压扁。
- 4x3 的星期栏必须只由布局中的一个专用视图提供，不能由列表项重复生成。

## 方案

- 共用七日格几何改为更靠左的起点与 8dp 右内边距；单元半径根据可用列距收缩，避免窄宽度重叠。
- 4x4 行从顶部开始以最高 28dp 的固定紧凑行高顺排；日课很多时才按可用高度收缩。
- 4x3 行与星期栏位图按布局实际内容宽度生成，避免 `fitXY` 横向压缩文字；左侧图标与名称仍以原始字号绘制。
- 4x3 保留唯一的顶部星期栏，列表行只绘制日课图标、名称和打卡方格。

## 验证

- 静态测试确认 4x4 使用行高上限、4x3 使用内容宽度，且星期栏 ID 仅出现于布局和 provider。
- 解析相关 Android XML。
- 运行周统计测试、Web 构建与 Capacitor Android 同步，不执行 Android Gradle 编译。
