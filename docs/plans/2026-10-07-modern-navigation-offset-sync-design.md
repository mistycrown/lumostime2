# 新版导航栏偏移设置不同步设计

## 目标

新版导航栏的 `navigation_new_background_settings` 仅保留在当前设备，不进入 JSON 导出和云同步数据。

## 方案

从 `appearanceBackupService` 的外观存储白名单中移除该 key。新版导航栏的启用状态、当前背景、自定义背景列表、透明模式和图片资源仍按现有逻辑同步。由于恢复逻辑只处理白名单字段，目标设备已有的本地偏移、缩放、拉伸和透明度不会被云端覆盖；新设备则使用本地默认值。

## 验证

更新 `appearanceBackupService` 回归测试，覆盖构建 payload 不包含该字段、应用同步数据不覆盖目标设备已有设置，以及显式旧 payload 中出现该字段时仍忽略它。
