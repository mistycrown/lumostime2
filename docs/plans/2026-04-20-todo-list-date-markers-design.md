# 待办列表详细视图日期标识设计

日期：2026-04-20

## 背景

待办列表页已经支持 `scheduledDate` 和 `deadlineDate`，也会在详细编辑和周视图里使用这些字段，但普通列表条目里还缺少直接可见的提示。结果是用户在列表里很难一眼区分哪些项目已经设置了安排日期或截止日期。

## 目标

- 仅在待办列表的详细视图中，为设置了安排日期或截止日期的项目显示日期标识。
- 紧凑视图保持不变，避免破坏现有信息密度。
- 不改动数据结构，只复用现有 `TodoItem` 字段。

## 方案

采用最小改动方案，在 `TodoView.tsx` 的 `SwipeableTodoItem` 右侧动作列顶部新增轻量日期标识：

- `scheduledDate` 显示为 `CalendarDays + MM.DD`，纵向排布。
- `deadlineDate` 显示为 `Flag + MM.DD`，纵向排布。
- 两个字段独立判断，有哪个就显示哪个。
- 不使用外框胶囊，只保留轻量图标与日期文本。
- 该行只在 `viewMode === 'loose'` 时渲染。

## 取舍

- 不把日期混进现有 tag/scope 行，避免语义混杂。
- 把日期放进右侧动作列，利用原本空白区域，避免挤压标题宽度。
- 不使用更强的高饱和 badge，避免让普通列表显得过于拥挤。
- 标题限制为最多两行，超出省略，避免超长标题挤坏顶部布局。
- 先使用月日格式满足快速识别需求；如果后续需要跨年区分，再补充年份策略。

## 验证

- 详细视图下同时设置安排日期和截止日期时，两种标识都可见。
- 仅设置其中一个日期时，只显示对应标识。
- 紧凑视图不显示这组标识。
- 运行 `npm run build` 做基础回归验证。
