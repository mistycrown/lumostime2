# 主题包贴纸覆盖升级设计

## 目标

同一主题包 ID 从旧版本覆盖导入新版本时，保持已使用的主题贴纸可读，并显示新版本的图片资源。

## 方案

- 使用稳定的主题命名空间贴纸 ID（主题 ID、贴纸组 ID、贴纸 ID）匹配旧版与新版资源。
- 覆盖导入时保留旧主题生成的贴纸组和选择器分组，更新匹配贴纸的 `imageFilename` 与缩略图文件名为新导入的随机文件名。
- 同步迁移历史日记心情中 `image:<文件名>` 形式的贴纸引用，使已使用的贴纸立即指向新版本图片。
- 新版本未再定义的主题贴纸会从组和选择器中移除，避免保留已删除图片的引用。
- 图片替换完成后才删除旧版本主题图片，继续使用既有删除记录和云同步流程。
- 完整删除主题仍移除全部主题贴纸及其图片。

## 验证

- 覆盖导入测试验证稳定贴纸 ID、历史心情引用保持可读，图片名替换为新版本资源，并验证旧文件删除。
- 运行主题包导入和应用相关测试及生产构建。
