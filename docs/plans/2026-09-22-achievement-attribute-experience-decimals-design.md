# Achievement Attribute Experience Precision Design

## Goal

Preserve character-attribute experience generated by each day's Achievement Bottle rules to two decimal places. Rule configuration values for experience per unit remain integers.

## Design

- Add one shared experience normalizer that rounds finite values to two decimal places and removes negative zero.
- Apply the normalizer when generating daily growth snapshots, normalizing stored snapshots, and aggregating attribute and total experience.
- Keep the existing integer normalization for configured `expPerUnit` values.
- Use shared two-decimal formatters in daily records, the experience chart, and the character profile so display does not re-truncate the calculated values.

## Verification

- Preserve existing integer and negative-experience behavior.
- Add regression coverage for a fractional daily result such as `1 / 3 * 10 = 3.33` and its aggregate totals.
- Run the focused Vitest suite and the production build.
