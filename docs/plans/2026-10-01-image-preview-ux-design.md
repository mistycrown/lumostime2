# 图片预览多图切换与长图阅读设计

## 目标

统一优化所有共享图片预览入口：同一记录含有多张图片时，可横向滑动切换；超长图片按屏幕宽度显示，并支持自然的纵向上滑阅读。画廊入口只切换当前记录的附件，不跨记录浏览。

## 方案

1. 扩展共享 `ImagePreviewModal` 的输入，兼容原有单图调用，同时支持包含 URL、下载文件名和标识的图片列表及初始索引。预览内部负责当前索引、页码和当前图片对应的下载/删除操作。
2. 多图预览采用浏览器原生横向滚动吸附分页，提供滑动切换、页码指示、桌面端左右按钮和键盘方向键。切图时重置缩放和旋转，避免上一张图片的状态影响下一张。
3. 预加载图片后根据自然尺寸识别超长图。普通图片继续使用现有缩放和旋转视图；超长图以可视区域宽度渲染到独立的纵向滚动容器，优先保证单指上下阅读不被缩放手势截获。
4. 各调用点按当前记录组织预览列表：新增/编辑记录、时间线、画廊、收藏时间线均传入该记录的全部附件；只有单张来源的调用继续使用兼容的单图路径。画廊点击图片时只传入对应 `log.images`。
5. 单张图片加载失败只显示该页的缺图状态，仍可切换其他图片。Android 返回键继续优先关闭确认删除框，否则关闭预览。

## 验证

- 覆盖图片列表归一化、初始索引和超长图判定等纯逻辑。
- 手动验证：单图原有缩放/旋转、同记录多图左右滑动、长图纵向滚动、当前图下载/删除、画廊不跨记录切换，以及 Android 返回键关闭行为。
- 运行相关 Vitest 测试与 `npm run build`。
