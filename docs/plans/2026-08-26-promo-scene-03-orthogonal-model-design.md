# Promo Scene 03 Orthogonal Model Design

## Purpose

Explain why LumosTime separates activity tags, scopes, and todos instead of deepening a single tag tree.

## Copy

- Heading: `不必再为每一件事，\n一层一层地造标签。`
- Body names the three independent dimensions with the same spoken-English course example.
- Closing: `一层标签装不下真实的生活。也许你需要完整的正交结构。`

## Product Surface

- The product surface is a purpose-built relationship view, not a scope detail page.
- A central `09:00 - 09:45 / 上课` record is the shared source of truth.
- Three equal columns for tag, scope, and todo connect to that record through the same line system.
- A final combination line reads `上课 × 说流利英语 × 本学期的口语外教课`.
- The scene deliberately avoids tree UI and nested category language.
