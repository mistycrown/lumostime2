# AI 对话输入框固定定位设计

## 目标

让 AI 首页和对话详情页底部的对话输入框始终固定在视口底部，并统一交互外观：左侧为无圆圈加号，右侧为发送按钮。

## 方案

- 继续复用 `AIBackfillChatModal.tsx` 当前共享 composer，不拆分发送逻辑。
- composer 使用固定定位，适配底部安全区，并保持现有发送/停止状态切换。
- 对话内容区域增加与 composer 等高的底部留白，避免最后一条消息被遮挡。
- 左侧加号移除圆形按钮容器，仅保留可点击的加号图标；右侧发送按钮保持现有视觉层级和禁用状态。

## 验证

- 运行 `npm run build`。
- 检查首页和已有会话详情页：输入框均固定在底部，滚动内容不被遮挡，加号无圆圈，发送按钮可用。
