# 日课周统计参考图差距修正设计

## 目标

消除当前预览与参考图之间最显著的差距：表格起点偏右、4x4 行距偏松，以及 4x3 出现重复星期栏。

## 方案

- 共用七日格继续向左移动，缩短日课名称与第一列方格的空隙，同时维持 8dp 右侧内边距。
- 4x4 将日课行高上限由 28dp 收紧到 24dp，保持上方日期与星期栏不变。
- 4x3 保留一个布局级星期栏；为 `RemoteViewsService` 适配器写入新的版本化 data URI，迫使启动器舍弃可能缓存的旧列表行视图。
- 4x3 单行 renderer 不绘制星期栏，星期文字仍只由专用 header renderer 产生。

## 验证

- 静态测试覆盖新的共享七日格几何、4x4 行高上限与 4x3 适配器版本 URI。
- 运行周统计测试、Web 构建与 Capacitor Android 同步；不执行 Android Gradle 编译。
