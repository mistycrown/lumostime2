# Memoir 日历背景单图填充设计

## 目标

将 Memoir 顶部日历背景统一为单张图片的填充呈现。移除“溢出”模式、五周/六周双图资源和相关调试入口，不再兼容或读取旧双图配置。

## 方案

- 设置界面只保留单图背景列表、上传、删除和透明度调节；不再显示模式切换或溢出调整入口。
- 背景服务仅维护单图资源、单一当前背景 ID 及其设置。旧双图本地存储不会被读取。
- 主题包的 Memoir 背景仅接受 `image` 字段；包含 `mode`、`fiveWeek` 或 `sixWeek` 的旧双图配置将被校验拒绝。
- 应用主题包时仅导入和选择一张 Memoir 背景图片。
- 图片引用、外观快照和默认主题补充逻辑同步移除双图与模式分支，避免旧配置继续保留或被恢复。
- 示例模板改用单张 `assets/memoir-calendar/background.png`，README 与 ZIP 内容同步更新。

## 错误处理与验证

- 缺少 `image` 或混入旧双图字段的主题包返回明确的配置错误。
- 更新或补充服务测试，覆盖单图接受和旧双图拒绝。
- 运行生产构建，确认类型检查与打包通过。
