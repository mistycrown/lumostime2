# 新版导航栏图标组设计

## 目标

在新版导航栏设置中支持使用图片替代五个导航入口的文字。内置图标组按固定顺序对应“记录、待办、脉络、档案、索引”；用户上传的图标组可由用户重新映射到五个入口。

## 交互设计

- 在导航背景图片选择区域之后增加独立的“导航图标”选择区域，采用与时间小友相近的紧凑方案选择布局。
- 内置提供 `粉色` 图标组，使用 `public/dchhicon/pink/1.webp` 至 `5.webp`。
- 主页面每个方案只显示一个代表图标和简短名称，不展开五入口预览。
- 用户可创建多个自定义方案；方案名称、五个入口映射、图标上传和删除都在编辑弹窗中完成。
- 自定义图标可删除；删除后，使用该图标的入口回退为文字。
- 选择“文字导航”时恢复原有文字显示；新版导航背景、旧版导航装饰和已有调试能力保持不变。

## 数据与持久化

- 自定义图片通过现有 `imageService` 保存到 `theme` 组，使用 `imageFilename` 作为稳定引用。
- 图标库、方案列表、当前方案和五个入口映射写入独立的 localStorage 键，并在图片引用收集服务中纳入清理保护。
- 外观备份服务扩展导航图标设置，确保导出/恢复时保留当前选择与自定义图片引用。
- 通过自定义事件同步设置页与底部导航，避免刷新才能看到效果。

## 渲染与兼容

- 新版导航开启且入口存在图片时显示图片；图片加载失败或入口未配置时显示原文字。
- 图片使用固定的可访问替代文本和尺寸约束，避免撑高导航栏；五个入口仍保持均分布局。
- 旧版导航继续显示文字，不读取新版图标配置。

## 验证

- 验证内置粉色组五个入口顺序。
- 验证多方案创建、选择、弹窗编辑、上传、映射、删除和文字回退。
- 验证刷新、外观备份恢复后的状态一致性。
- 执行 `npm run build`，并运行受影响服务的 Vitest 测试。
