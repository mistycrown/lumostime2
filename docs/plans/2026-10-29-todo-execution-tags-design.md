# 待办执行标签设计

## 目标

让用户可以在待办上随手添加“低精力、家里、晚上”等执行标签，以及自定义标签，为后续 AI 按当前状态推荐任务提供可解释的输入；整个交互保持标签选择，不引入必填表单。

## 设计

- 执行标签与现有活动标签分离。现有 `linkedActivityId` 继续用于日志关联、统计和活动标签展示；待办新增可选的 `executionTags` 字段。
- 系统预置标签按语义分组：精力（低/中/高，单选）、场景（家里、办公室、外出、电脑前、手机即可、需要安静，可多选）、时段（早晨、上午、下午、晚上、深夜，可多选）。
- 用户可输入任意自定义执行标签；自定义标签归入 `custom` 分组，不要求用户再填写分类。
- 任务详情和创建任务流程使用同一个轻量标签选择器，点击标签立即更新草稿；没有执行标签时只显示添加入口。
- 复制待办时保留执行标签；创建子任务时不自动继承执行标签，因为父任务与子任务的执行负荷可能不同。
- 执行标签以稳定预置 ID 和分组保存，AI 上下文可读取分组和名称；旧待办缺少字段时按空数组处理，不需要迁移。

## 首版范围

首版包含数据类型、预置标签、自定义标签、待办详情/创建编辑入口、复制保留和基础测试；不包含执行标签管理页、标签筛选、地理位置识别或主动排程推荐。
