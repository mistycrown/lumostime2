# 新版导航图片图标下显示文字设计

## 背景

新版底部导航支持使用粉色内置图标或自定义图片图标，但当前图片模式会隐藏导航文字。需要增加一个可选开关，让用户在保留图片图标的同时，在图标下显示较小的导航文字。

## 目标与范围

- 仅在新版导航已开启、且当前选择了图片图标方案时显示该开关。
- 开关默认关闭，保持现有用户的“仅显示图片”行为不变。
- 支持粉色内置图标和自定义图标方案。
- 设置刷新应用后仍然有效。
- 图片加载失败时沿用现有的文字回退行为。

## 方案

新增独立的 `showLabelWithIcon` 设置，不把它扩展为新的图标模式。设置通过导航图标服务保存到 `localStorage`，并复用现有的导航图标变更事件通知底部导航即时刷新。

设置面板在 `NavigationIconSelector` 中增加“图标下显示导航文字”开关；只有当前模式为 `pink` 或 `custom` 时渲染。底部导航读取该设置：开启时，图片与导航文字使用纵向布局，文字使用约 10px 的小字号；关闭时保持原有图片布局。激活状态继续使用现有颜色和图片透明度差异。

## 数据流

1. 用户在新版导航设置面板切换开关。
2. `navigationIconService` 更新 `navigation_icon_selection_v1` 中的 `showLabelWithIcon` 字段并派发 `NAVIGATION_ICON_CHANGE_EVENT`。
3. `BottomNavigation` 接收事件并重新读取选择状态。
4. 当图片方案有效且开关开启时，导航项同时渲染图标和小号文字。

## 兼容与异常处理

- 旧版本没有该字段时按 `false` 处理。
- 文字模式下不显示该开关，也不影响原有文字导航。
- 自定义方案被删除或图标加载失败时，沿用现有选择降级与文字回退逻辑。

## 验证

- 检查默认状态为关闭，旧行为不变。
- 分别验证粉色方案和自定义方案的开关即时生效。
- 刷新后确认开关状态保持。
- 验证图片加载失败时仍能显示导航文字。
- 运行相关测试和 `npm run build`。
