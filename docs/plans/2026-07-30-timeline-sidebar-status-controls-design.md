# 脉络侧栏状态控件设计

## 目标

使脉络侧栏的数字日课和待办状态按钮符合紧凑列表的直接操作预期，同时保留正文的快捷编辑和拖拽职责。

## 方案

- 数字类型的手动日课使用圆形描边标记，并显示当前次数。现有状态逻辑保持不变：每次点击加一，达到目标后下一次点击重置为零。
- 自动日课继续使用方形标记；普通手动日课保持圆形勾选标记，三类日课可在单行内区分。
- 每个待办行拆为独立的前置完成按钮和正文交互区。点击前置圆圈只切换完成或未完成，不会打开快捷编辑；点击正文打开快捷编辑，未完成正文仍可向左拖入时间轴。
- 完成切换复用应用现有的待办保存入口，并沿用当前快捷操作的实际操作时间作为 `completedAt`。

## 验证

- 覆盖数字日课与待办状态标记的纯逻辑路径。
- 运行相关 Vitest 测试及生产构建。
