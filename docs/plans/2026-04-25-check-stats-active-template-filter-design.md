# 日课统计仅显示启用模板设计

日期：2026-04-25

## 目标

让统计页的 `check` 视图只显示“日课模板中仍然存在且当前启用”的日课项。

## 范围

- 修改主统计页的 `StatsView` 日课统计汇总逻辑。
- 不修改日课页、周复盘、月复盘中的其他统计展示。
- 不修改 `dailyReviews` 的历史数据。

## 方案

1. 给 `StatsView` 增加可选的 `checkTemplates` 参数。
2. 仅在 `check` 视图汇总时，根据 `enabled && isDaily` 的模板和其现存条目构建白名单。
3. 汇总 `dailyReviews.checkItems` 时，只统计命中白名单的条目。
4. 主统计页显式传入 `checkTemplates`，其他嵌入式 `StatsView` 不传，避免扩大影响范围。

## 预期结果

- 已停用模板中的日课不再出现在统计页 `check` 视图。
- 已从模板中删除的历史日课不再出现在统计页 `check` 视图。
- 仍在模板中且启用的日课保持现有统计方式不变。
