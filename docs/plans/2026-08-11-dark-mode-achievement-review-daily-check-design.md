# 深色模式：成就、回顾与日课总览视觉修复设计

日期：2026-08-11

## 目标

- 深色模式下保留成就瓶在浅色模式中已有的瓶型、玻璃层次与主题配色。
- 修复成就页底部选项卡的浅色选中态，使文字与图标保持清晰可读。
- 让回顾总览和日课总览的列表条目在深色模式中保持透明底，不再显示灰色块状底色。

## 方案

1. 成就瓶使用语义 CSS 自定义属性承接每套现有调色板，并由专用类绘制外壳、内腔和装饰层。深色模式的通用浅色替换规则不再覆盖这些层，因此不需要新增或调整任何瓶子主题色。
2. 为成就页的选中选项卡增加语义类。在深色模式中明确保留浅色选中背景，并把文字和图标设为深色。
3. 为回顾和日课总览的行增加语义类。在深色模式中把默认及交互底色设为透明，保留分隔线与内容层级。

## 验证

- 运行生产构建，确保 TypeScript 和样式构建通过。
- 检查浅色、深色模式下成就页、回顾总览、日课总览的关键对比度和行背景。
