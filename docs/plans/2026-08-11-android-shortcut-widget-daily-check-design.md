# Android 快捷栏日课交互设计

## 目标

修复 Android 快捷栏小组件中的日课打卡状态回放，并支持点击未占用的背景区域手动刷新。

## 交互规则

- 布尔型日课按 `未完成 -> 完成 -> 未完成` 循环。
- 数值型日课按 `0 -> 1 -> ... -> 目标值 -> 0` 循环。
- 标题继续用于切换小组件模板。
- 日课图标和标签继续用于打卡；未被任何控件占用的根背景区域用于刷新当前小组件。

## 数据流

原生端读取本地镜像的日课进度，先按当前手动模式计算本次动作：布尔项为 `toggle`，数值项为 `cycle`。它立即写入镜像进度以更新小组件视觉反馈，并将同一个动作写入待同步队列。

应用恢复或重新获得前台状态时，React 端逐条读取待同步日课动作，调用既有日课工具按动作更新当天日报，再将最新日课镜像同步回原生端。这样离线连续点击不会被固定的“仅完成一次”语义截断。

空白刷新由小组件 provider 处理：接收刷新广播后只重绘当前实例，不改变模板绑定或日课数据。

## 验证

- 单元测试覆盖布尔 `toggle` 与数值 `cycle` 的回放状态。
- 类型检查/构建确认 TypeScript 桥接契约一致。
- Android 原生代码通过 Gradle 编译检查；不在本工作区执行 APK 构建。
