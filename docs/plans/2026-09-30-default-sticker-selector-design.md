# 默认贴纸选择器紧凑化设计

## 目标

将 Emoji 与 Sticker 设置页中占据较长篇幅的“Selector 默认页”选项列表，移动到“投喂小鱼干 / Icon Tab / Sticker 集”区域下方，并改为适合移动端的紧凑入口。

## 交互设计

- 从 Emoji 与 Sticker 设置页移除原有的“Selector 默认页”卡片。
- 在“投喂小鱼干 / Icon Tab / Sticker 集”的最下方显示单行“默认贴纸”设置项，右侧展示当前默认页名称和展开箭头。
- 点按该设置项，从底部弹出单选面板。
- 面板提供 Emoji 页和当前可用的贴纸页；启用新版贴纸选择器时，改为展示其实际可用的大分组。选中后立即保存并关闭面板，当前选项显示勾选。

## 实现边界

- 复用 `defaultSelectorPage` 和 `setDefaultSelectorPage`，不改变持久化格式、默认值或心情选择器的跳转逻辑。
- 删除原先页面上方的长列表，仅变更入口位置与交互。
- 构建项目以验证 TypeScript 和生产打包。
