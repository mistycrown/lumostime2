# 标签详情热力图渲染修正设计

## 目标

- 移除标签详情“星期 × 小时热力图”未着色格子的灰色描边。
- 让“选项热力图”展示所有有统计数据的选项。
- 选项超过调色板长度时，按调色板顺序循环使用颜色。
- 选项色块下方只显示选项文字，不显示附加数字。

## 方案

在 `ActivityAttributeStatistics` 的现有渲染组件中做局部修正：

1. 星期 × 小时热力图移除格子的 `border-stone-200` 类，保留现有背景色、透明度、圆角和网格间距。
2. 选项热力图移除选项列表的前 8 项截断，使用全部有数据的选项；颜色通过 `index % palette.colors.length` 循环映射。
3. 选项标签沿用现有标签来源，仅渲染选项文字；统计值继续保留在无障碍标签和悬浮提示中。

## 验证

- 检查代码中不存在选项热力图的 8 项截断逻辑。
- 执行 `npm run build`，确认 TypeScript 和生产构建通过。
- 检查 git diff 仅包含本次设计文档与热力图相关代码变更。
