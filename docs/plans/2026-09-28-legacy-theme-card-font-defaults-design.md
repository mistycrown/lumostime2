# 旧版主题预设的卡片与字体默认值

## 目标

旧版内置主题切换时，清除当前卡片背景选择并恢复默认字体，避免残留上一个新版主题或主题包的外观状态；保留用户已上传的卡片背景组与字体文件。

## 方案

扩展 `ThemePreset`：

- `cardBackgroundGroupId?: string | null`：`null` 表示不使用卡片背景。
- `fontId?: string`：`default` 表示系统默认字体。

所有内置旧版主题显式声明这两个值。主题应用服务仅在字段存在时调用卡片背景与字体服务，因此不会改变缺少这些字段的预设或快照主题。

## 验证

扩展主题预设服务测试，断言旧版预设会将卡片背景选择设为 `null`、字体设为 `default`，并且不涉及任何素材删除操作。
