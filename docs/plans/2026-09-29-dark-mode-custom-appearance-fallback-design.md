# 深色模式自定义外观回退设计

## 目标

深色模式下，暂时停用无法完整适配的自定义视觉设置，统一使用应用默认深色外观；浅色模式下自动恢复用户已保存的设置。

## 范围

仅处理以下配置：

- 整体背景
- 卡片背景
- 新版与旧版导航栏背景
- Memoir 日历背景
- 透明标题栏

图标主题、颜色方案、字体及其他主题偏好保持现有行为。

## 设计

主题模式解析后，应用根节点维护一个仅运行时使用的“自定义外观已禁用”标记。显式深色模式以及“跟随系统”解析为深色时设置该标记；浅色时移除。

五类目标模块均根据此有效状态决定渲染：标记存在时跳过用户自定义资源和透明标题栏，直接渲染模块既有默认外观；标记移除后重新读取并应用现有配置。用户的 LocalStorage、同步和导入导出数据不会被修改。

## 验证

- 为主题模式解析/根节点标记增加回归测试，覆盖浅色、深色与系统模式。
- 人工验证五类模块在深浅切换后的即时回退与恢复。
- 执行 `npm run build`。
