# 新版 Sticker 选择器设计

## 背景

Memoir 的 `MoodPicker` 当前按 Emoji 和每个 16 张贴纸小组分页，贴纸页使用固定 4×4 网格。需要新增一个独立的新样式，并通过“投喂小鱼干”中的开关启用。启用后只替换 sticker 选择器；Emoji 保持原有选择方式。

## 目标

- 增加“开启新版sticker选择器”开关。
- 新版支持把多个现有 16 张小分组合并为一个可滚动的大分组。
- 合并后的大分组采用手动命名，原始小组在新版选择器中不再单独出现。
- 第一次开启且没有配置时，自动将 `water1`、`water2`、`water3` 合并为“水彩”大分组。
- 旧版选择器在关闭新版后保持现状，历史贴纸值和贴纸资源不变。

## 方案

采用显示层合并，而不是复制或删除贴纸资源。持久化配置记录新版开关和大分组布局；每个大分组引用若干原始 sticker set ID。新版选择器在运行时解析引用并展开贴纸，旧版继续直接读取 `stickerService.getAllStickerSets()`。

建议配置结构：

```ts
interface StickerSelectorGroup {
  id: string;
  name: string;
  sourceSetIds: string[];
}

interface NewStickerSelectorConfig {
  enabled: boolean;
  groups: StickerSelectorGroup[];
}
```

配置进入 `SettingsContext`，写入本地存储，并纳入现有导出、导入和同步 payload。缺失或无效的小组 ID 在读取时过滤；空大分组不阻塞选择器。

## 设置页交互

在“投喂小鱼干”页的 Sticker 区增加开关和新版分组管理区域：

1. 切换开关为开启时，如果 `groups` 为空，自动创建“水彩”大分组并包含 `water1`、`water2`、`water3`。
2. 用户可以新建大分组、手动输入名称、勾选多个现有小组并保存。
3. 一个原始小组同一时间只允许归属一个大分组；未归属的小组在新版中作为单独大分组显示。
4. 重命名只改布局配置；删除大分组只解除归属，原始小组恢复为未归属状态。
5. 不删除静态贴纸文件，不改变历史 `DailyReview.moodEmoji` 值。

## 选择器交互

- 新版开启时，Emoji 仍单独占一页并保持原有 4×4 网格。
- Sticker 页按大分组横向切换；组内使用纵向可滚动的瀑布流/多列布局，不再限制为 16 宫格。
- 每张贴纸继续通过 `IconRenderer` 渲染，点击后沿用现有 `onSelect` 并关闭弹窗。
- `defaultSelectorPage` 在新版下存储 Emoji 或大分组 ID；关闭新版时恢复旧版小组分页逻辑。

## 数据兼容与边界

- 关闭新版完全走原有渲染分支，不改变旧版行为。
- 配置引用不存在的小组时自动过滤；若大分组过滤后为空则隐藏。
- 删除或编辑原始自定义贴纸组后，选择器动态刷新并清理失效引用。
- 合并配置和开关随现有设置导出/导入/同步，旧数据导入时使用默认关闭状态。

## 验证

- 首次开启自动得到“水彩”大分组，包含三组水彩贴纸。
- 新建、重命名、合并、拆分大分组后，刷新页面仍保持配置。
- 关闭开关后旧版分页、默认页和选择行为不变。
- 新版瀑布流可纵向滚动，点击任意贴纸仍正确写入并关闭。
- 历史记录中的旧 emoji、内置 sticker、自定义 sticker 均可正常显示。
- 导出再导入、同步恢复后，新版开关和分组配置保持一致。
