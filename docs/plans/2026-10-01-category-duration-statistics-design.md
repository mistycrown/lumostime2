# 分类时长自定义图表修复设计

## 目标

修复分类详情中的分类时长自定义图表，使其与其他统计卡片保持一致：卡片之间只显示一条分隔线，数值概览使用小时/分钟格式，星期 × 小时热力图清晰显示数字小时轴。

## 方案

1. 保留 `ActivityAttributeStatistics` 外层统一的 `divide-y` 分隔方式，为旧数值渲染器增加可选的内部顶边线开关；分类时长卡片关闭内部顶边线，避免与外层分隔线重复。
2. 将标签时长和分类时长的合成数值字段统一识别为时长字段，继续复用现有 `formatHoursMinutes`，并隐藏“时长”单位文本。
3. 调整星期 × 小时热力图的小时标题，去除可截断样式，保留 `00`、`01` 等数字小时显示，并为多列场景提供稳定的最小列宽与横向滚动空间。

## 验证

- 更新组件头部变更记录。
- 运行相关 Vitest 测试。
- 运行 `npm run build`。
- 检查 git diff，确保不覆盖用户已有的未提交改动。
