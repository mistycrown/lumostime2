# 成就瓶收藏设计

## 目标

在成就瓶详情区新增一个“收藏”tab，让用户可以使用光点兑换瓶子收藏，并把已经兑换到手的瓶子以“货架陈列”的方式展示出来。同时，收藏兑换也要像奖励兑换一样进入记录体系并参与光点扣减。

## 已确认决策

- 成就页顶部 tab 从 `记录 / 规则 / 兑换` 扩展为 `记录 / 规则 / 兑换 / 收藏`
- 收藏使用独立数据模型，不和现有奖励列表混用
- 收藏兑换会消耗光点，并立即影响当前可用光点
- 收藏兑换单独记录到“收藏记录”，记录页中新增对应区块
- 展示区不使用正方形卡槽，而是保留瓶子原始宽高比，做成底部对齐、紧密摆放的货架效果
- 当前 `public/bottle` 下已有 16 个瓶子素材，先全部作为默认可兑换收藏，单价统一为 `500` 光点

## 数据设计

### AchievementCollection

用于定义可兑换的收藏商品。

- `id`
- `name`
- `cost`
- `imagePath`
- `description?`
- `enabled`
- `createdAt`
- `updatedAt`

### AchievementCollectionRecord

用于记录用户已经兑换成功的收藏实例，同时也直接作为“我的收藏”展示数据源。

- `id`
- `collectionId`
- `collectionName`
- `cost`
- `imagePath`
- `redeemedAt`
- `note?`

## 交互设计

### 收藏 Tab

收藏 tab 分成两段：

1. `Collections / N`
   右侧提供“新增收藏”按钮，样式直接复用现有“新增奖励 / 新增规则”的按钮语言。列表中的每一项支持：
   - 展示瓶子缩略图
   - 展示名称与光点成本
   - 兑换按钮
   - 编辑按钮

2. `My Collection / N`
   展示已拥有的收藏瓶子。布局采用货架式陈列：
   - 瓶子保持原始比例
   - 同一层统一底部对齐
   - 横向间距压紧
   - 每层下方有淡淡的层板线，强化“摆在货架上”的感觉

### 记录 Tab

记录页保留原有：

- 每日记录
- 奖励兑换记录

并新增：

- 收藏记录

收藏记录与奖励记录一样展示名称、光点消耗和兑换时间，并支持删除。删除后视为撤销这次收藏兑换，对应收藏实例和光点扣减一并回退。

## 数据流

- `AchievementContext` 新增收藏商品和收藏记录状态
- `dataRepository` 新增收藏商品、收藏记录的持久化 key
- `availableStars` 与 `totalRedeemedStars` 的计算从“只统计奖励兑换”改为“统计奖励兑换 + 收藏兑换”
- 收藏兑换成功时：
  - 检查当前光点是否足够
  - 生成收藏记录
  - 记录进入“我的收藏”
  - 记录进入“收藏记录”
  - 当前可用光点实时减少

## 默认素材策略

- 首批默认收藏直接映射 `public/bottle/01.png` 到 `public/bottle/16.png`
- 默认名称使用稳定编号命名，便于后续逐个替换成正式收藏名
- 若用户后续补充更多瓶子素材，可继续通过“新增收藏”录入新的图片路径与名称

## 本次实现范围

- 新增“收藏”tab
- 新增收藏商品与收藏记录的数据结构
- 提供默认 16 个瓶子收藏，单价统一为 500 光点
- 支持新增、编辑、删除收藏商品
- 支持兑换收藏
- 支持货架式展示“我的收藏”
- 在记录页新增“收藏记录”
- 收藏记录删除后同步回退对应收藏与光点消耗

## 暂不纳入
