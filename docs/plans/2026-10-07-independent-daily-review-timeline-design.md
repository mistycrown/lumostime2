# 独立日报时间线区块设计

## 目标

在节点详情的“时间线”标签中，将关联日报作为独立内容区块展示，而不是混入日志时间线；同时消除日志行与节点链接按钮的非法嵌套。

## 方案

- `DetailTimelineCard` 在历史日志区之前渲染“关联日报”区块。每条日报使用独立卡片，保留日期、问题、回答和打开详情操作。
- 日报仅按当前月份/全部视图筛选，不再向日志日期分组函数注入日期占位，因此日报不会生成空日志日期块。
- 日志记录继续支持整行打开编辑，但整行改为非原生按钮容器，并补充 Enter/Space 键盘行为；`NodeText` 内部节点链接按钮保持独立可操作。
- 日报答案中的节点链接仍使用共享 `NodeText` 渲染，但日报卡片自身不再包裹节点链接按钮。

## 验证

- 单元测试确认日报只在独立区块出现，且不会改变日志日期分组。
- 组件烟测确认节点链接、日志打开和日报打开行为没有回归。
- 执行 `npm run build` 与 `git diff --check`。
