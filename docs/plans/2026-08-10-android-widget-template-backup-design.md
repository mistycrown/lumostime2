# Android 小组件模板备份与同步设计

日期：2026-08-10

## 目标

将安卓小组件模板纳入统一 JSON 导出与云同步。用户在新设备恢复云端数据或导入备份后，应获得原有的小组件模板，无需重新配置。

## 范围

- 备份根对象新增可选 `widgetTemplates` 数组，来源为 Web 层的 `lumostime_widget_templates_v1`。
- 手动 JSON 导出与所有云同步上传共享该字段。
- 导入 JSON 与云端恢复检测到该字段时，规范化并覆盖本地模板；缺失该字段的旧备份不改变本地模板。
- 模板恢复通过既有 `saveWidgetTemplatesToStorage` 触发更新事件，由现有 Android 小组件桥接重新下发原生模板与运行时数据。
- 用户保存、编辑或删除模板时，复用模板更新事件触发自动云同步。

## 方案选择

采用现有 `widgetService` 作为模板的唯一序列化与恢复入口。相比直接读写 localStorage，该方案会沿用模板 ID、槽位、尺寸与追踪日历配置的规范化逻辑，并自动通知已挂载的小组件桥接。

恢复采用“备份字段存在即覆盖”策略。备份中的模板与用户数据的其他配置保持一致；旧备份不含该字段时保持兼容，不清空当前设备的模板。

## 验证

- 单元测试确认模板保存后的读取与更新事件行为。
- 数据校验测试确认 `widgetTemplates` 只接受数组，且旧备份仍可通过。
- 构建项目，确认 TypeScript 类型检查与 Vite 打包通过。
