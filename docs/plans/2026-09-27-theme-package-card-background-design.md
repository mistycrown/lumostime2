# 主题包卡片背景组设计

## 目标

将卡片背景组作为主题包的正式资源接入导入、模板、删除与云同步生命周期。

## 规则

- 一个主题包最多定义一个 `resources.cardBackgroundGroups` 项；多个组会在导入校验阶段被拒绝。
- 导入 ZIP 后即创建该主题命名空间下的卡片背景组，即使主题暂未应用。
- `apply.cardBackground` 只控制是否自动选中该组及其透明度；未配置时保留用户当前选中组。
- 删除主题时先移除该主题的卡片背景组和选择状态，再通过图片服务删除主题资源及缩略图，以便写入云端删除记录并更新图片引用清单。

## 模板与同步

- 两份主题模板均包含 `assets/card-backgrounds/` 目录和 `.gitkeep`。
- 卡片背景图片作为 `theme` 图片保存，沿用现有图片清单、上传事件和删除事件；自动同步与手动同步均可处理这些变化。

## 验证

- 覆盖单组资源导入、超过一组的校验失败、应用自动选中和删除时的组与图片清理。
- 运行主题包相关测试与生产构建。
