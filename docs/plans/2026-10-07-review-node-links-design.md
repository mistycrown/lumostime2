# 回顾节点关联设计

## 目标

让日报、周报、月报引导回答中的节点链接共享同一套节点能力，并在节点详情时间线的独立“关联回顾”区域展示；时间线的“本月 / 全部”筛选同时作用于三类回顾。

## 数据与索引

- 扩展节点索引的回顾答案记录，记录 `kind`（daily/weekly/monthly）、回顾 ID、问题、答案和周期起止日期。
- 节点自动发现、共现关系、最新时间、重命名、合并和潜在关联统一扫描三类回顾答案。
- 周报和月报继续复用现有 `NodeTextEditor`，不新增输入控件。

## 节点时间线与打开行为

- `DetailTimelineCard` 接收统一回顾条目，独立渲染“关联回顾”卡片，不把它们插入日志日期轨道。
- “本月”按回顾周期与当前显示月份有重叠判断：日报按当天，周报按周起止，月报按月起止；“全部”不过滤。
- 卡片显示类型和周期，点击分别打开日报、周报或月报的引导页。

## 兼容与验证

- 保留旧日报索引数据的行为，新增周报/月报为空时不改变现有节点结果。
- 重命名/合并需同步更新三类回顾答案。
- 测试覆盖节点输入链路、三类索引与重命名、月份重叠筛选、卡片回顾类型和打开导航。
