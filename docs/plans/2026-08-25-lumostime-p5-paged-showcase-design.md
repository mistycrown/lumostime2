# LumosTime p5.js 横向展示页设计

## 目标

给对时间管理感兴趣、但难以开始或坚持的人，提供一个可以自行浏览也可以直接录屏的产品理念展示页。它不是自动播放的视频播放器，而是一个有连续动效的完整网页。

## 结构

1. 从一次开始：一个时间点变成可见轨迹。
2. 三种关系：标签、领域、待办与时间记录的正交关系。
3. 看见时间：环形分布、一周日程、日历、趋势折线。
4. AI 陪伴：自然语言补记、主动唤醒、来信/小报。
5. 随处开始：NFC、桌面小组件、场景入口。
6. 每一步都算数：成就、经验、属性与人生的成长计划。
7. 品牌收束：雨帘、花枝、飞鸟与 slogan。

## 交互与技术

- p5.js 负责背景、图表、关系图、粒子和自然动效。
- 通过箭头、键盘、滚轮和触摸手动切换章节。
- 页面切换使用短暂的横向缓动；当前页内部动画持续运行，但不自动跳转下一页。
- 不引用旧 HTML 页面或旧截图，确保展示页是独立工程。
- `window.setPage(index)` 和 `window.renderPageAt(index, time)` 为录屏和固定帧验证保留控制接口。

## 视觉语言

纸张底色、石墨文字、绿色/蓝色/橙色/紫色节点，配合细线网格和低幅度粒子运动。末页借用雨、枝、花、鸟的自然运动原则，强调“从开始，到看见自己”的品牌收束。
