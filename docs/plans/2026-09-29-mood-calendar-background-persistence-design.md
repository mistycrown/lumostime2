# 心情日历背景持久化修复设计

## 目标

保证用户选择的 Memoir 心情日历背景在刷新、重启、页面切换和云同步后稳定显示，同时避免异步图片水合覆盖并发新增或导入的背景记录。

## 方案

- 背景服务提供幂等、可复用的水合入口；并发调用共享同一个进行中的 Promise。
- `MoodCalendar` 挂载时主动水合，不再依赖个性化设置页被打开。
- 水合结果按背景 ID 合并到最新存储快照，只更新 URL 缓存，不用旧列表覆盖新列表。
- 临时 `blob:` URL 和 `data:` URL 都只保存在运行时缓存中；localStorage 只保存稳定元数据和 `imageFilename`。
- `moodCalendarBackgroundChange` 纳入外观自动同步事件，使选择、透明度和列表变化更新同步时间戳。
- 图片读取失败时保留选中 ID，并输出可定位的警告；后续水合仍可重试。

## 数据流

1. 上传图片后，`imageService` 持久化文件并返回稳定文件名。
2. 心情日历背景服务保存背景元数据，把临时显示 URL 放入内存缓存。
3. 应用冷启动后，心情日历挂载并调用水合入口。
4. 服务根据 `imageFilename` 取回可渲染 URL，按 ID 写入运行时缓存并发送刷新事件。
5. 组件收到事件后重新解析选中背景并渲染图片。
6. 用户选择背景或调整透明度时，同一事件触发外观自动同步。

## 错误与并发

- 同时发生多次水合时复用同一任务，避免重复创建对象 URL。
- 水合期间新增、删除或导入背景时，以完成时的最新列表为准；已删除记录不会被重新插入，新记录不会被旧快照覆盖。
- 单张图片读取失败不影响其他背景；失败记录保留元数据，便于图片恢复后重试。

## 验证

- 服务测试覆盖临时 URL 不落盘、冷启动水合、共享水合任务和并发新增保护。
- 组件测试/源码约束覆盖心情日历挂载时主动水合。
- 同步测试/源码约束覆盖心情日历背景事件已加入外观监听。
- 运行相关 Vitest、TypeScript/Vite 构建，并人工检查目标 diff。
