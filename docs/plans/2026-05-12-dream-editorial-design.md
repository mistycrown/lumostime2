# Dream 页面极简印刷化改版设计

## 目标

- 去掉 Dream 页面当前明显的“外卡片 + 内卡片 + 胶囊按钮堆叠”观感。
- 让内容尽量直接渲染在页面背景上，只依赖留白、细分隔线和字重建立层级。
- 保留现有 Dream 交互能力，包括：
  - 领域切换
  - 新增/编辑/删除领域
  - 启用/停用领域
  - 运行 `dream`

## 采用方案

采用桌面端左右双栏、移动端单栏折叠的编辑稿布局。

- 左栏：Dream 领域目录
- 右栏：当前领域正文
- 中间只保留一条淡分隔线

相比顶部胶囊标签，这个方案更适合 Dream 领域逐渐增多后的浏览和切换，也更贴近极简印刷页面的目录 + 正文关系。

## 视觉原则

- 背景使用浅纸面色，而不是白底卡片叠加。
- 标题与正文直接排在背景上。
- 只在必要位置保留细边线：
  - 顶部标题栏底线
  - 左右栏分隔线
  - 当前领域标题下分隔线
  - Dream 观察条目之间的分隔线
- 操作按钮统一改成轻量细边按钮，减少高饱和大色块。

## 结构调整

### 1. 页面头部

- 保留 `Dream` 标题。
- 保留 `新增领域`、`运行 dream`、关闭按钮。
- 按钮样式改轻，弱化胶囊感和大面积填充。

### 2. 领域编辑器

- 继续保留输入区，但从厚卡片改为“内联编辑纸条”样式。
- 使用细边线和低对比背景，避免和正文抢层级。

### 3. 领域目录

- 从一组圆角标签改成目录式条目列表。
- 选中状态用更深文字和更明确的下边线表达。
- `on/off` 状态缩成轻量辅助标记。

### 4. 当前领域内容

- 标题、备注、操作按钮直接排在正文页顶。
- 删除确认改为内联警示行，而不是另一块强调卡。

### 5. Dream 观察列表

- 每条观察改成正文段落 + 元信息行。
- 元信息包括观察窗口、状态、更新时间、来源。
- 条目之间只用 `divide-y` 和留白分隔。

## 预期结果

- 页面整体更安静、更像编辑稿或档案页。
- 层级由排版和留白主导，而不是由卡片边框主导。
- 在保持现有功能完整的前提下，Dream 页面会更接近仓库既有的 editorial UI 方向。

## 验证

- 已完成 Dream 页面 JSX 和样式重排。
- `npm run build` 未能完成，但失败点是现有 Vite HTML 输出路径问题，不是本次 Dream 页面 JSX 报错。
- `npx tsc --noEmit` 也存在仓库内其他模块的既有类型错误，未显示本次 Dream 区块新增报错。
