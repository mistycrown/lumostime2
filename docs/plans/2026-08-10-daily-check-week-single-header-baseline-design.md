# 日课周统计单星期栏基准设计

## 目标

先将 4x3 日课周统计固定为唯一星期栏、稳定行高和无文字压缩的基准样式，再将相同行与方格样式迁移给 4x4。

## 4x3 结构修正

- 移除父布局中的独立星期栏 `ImageView`。
- `RemoteViewsService` 的第一项改为唯一星期栏，日课从第二项开始渲染。
- 服务提供两个视图类型：星期栏与日课行；空状态时不产生星期栏。
- 适配器 data URI 升级，确保启动器以新的集合结构重建列表。

## 4x4 迁移原则

- 使用 4x3 的日课行高度、方格尺寸与七列间距作为唯一参考。
- 左侧名称与第一列方格保持紧凑间距；右侧保留清晰但不过窄的内边距。

## 验证

- 静态测试验证 4x3 只有集合内星期栏、两个视图类型与新的适配器版本。
- 运行周统计测试、Web 构建与 Capacitor Android 同步；不执行 Android Gradle 编译。
