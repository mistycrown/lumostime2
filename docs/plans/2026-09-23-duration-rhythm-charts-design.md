# 标签与分类时长节律图设计

## 目标

在标签属性和分类属性的统计 Tab 中，为“标签时长”和“分类时长”增加两种共享图表：时间轨道环与花瓣时序图。两种图表观察一段时间内活动在一天 24 小时中的典型分布，不承担逐日回溯。

## 范围

- 复用 `ActivityAttributeStatistics` 的 `tagDuration` / `categoryDuration` 数据来源。
- 新增 `tagDurationTimeOrbit` 与 `tagDurationPetalTimeline` 两个统计卡片类型。
- 两种图表仅开放当前自然周和当前自然月两个统计范围。
- 保留已有的箱线图、星期 × 小时热力图及其他统计卡片。

## 数据流

日志先按选定的自然周或自然月过滤，再把每条记录按其与每个整点小时的重叠分钟数分配到 24 个 `HourBucket`：

```ts
interface HourBucket {
  hour: number;
  minutes: number;
}
```

聚合结果同时提供总分钟数和有记录的本地日期数，用于中心摘要。跨小时日志必须拆分，不能只按开始小时计入。

## 图形表达

### 时间轨道环

- 0 点在顶部，6/12/18 点分别位于右/下/左。
- 固定三层轨道：外层高活跃、中层中等活跃、内层低活跃。
- 每个小时的角度位置表示时间，弧段长度表示该小时持续分钟数，所在轨道表示强度层级。
- 强度按 24 个小时桶的相对值分为低/中/高；空桶不显示弧段。
- 中心显示总时长和记录天数，并提供每小时无障碍标签与原生悬浮信息。

### 花瓣时序图

- 24 个花瓣围绕同一时间轴排列，0 点在顶部。
- 花瓣长度表达该小时持续分钟数，透明度和颜色使用当前统计调色板。
- 中心显示总时长；外围显示 0/6/12/18 点刻度。
- 每个花瓣提供小时、持续时长和占比的无障碍标签与原生悬浮信息。

## 配置与兼容

- 扩展卡片类型、类型能力映射、规范化默认范围、卡片编辑器选项和卡片标题映射。
- 新图表的范围选项为 `week` / `month`；新增 `week` 范围按周一至周日计算，不复用滚动 7 天语义。
- 历史卡片数据保持可规范化，现有类型和范围不迁移。

## 验证

- 为范围过滤、跨小时拆分、卡片类型能力和默认范围补充单元测试。
- 运行相关 Vitest 测试与 `npm run build`。
- 手动检查标签详情和分类详情的统计 Tab，验证空态、周/月切换、响应式布局及中文文本显示。
