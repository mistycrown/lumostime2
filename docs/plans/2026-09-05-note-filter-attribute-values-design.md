# 备注筛选匹配属性值设计

## 目标

当自定义筛选器使用未带前缀的关键词（备注字段）时，除记录备注外，同时匹配该记录已保存的属性值文字。属性名称不参与匹配。

## 数据流

`matchesFilter` 根据日志的 `categoryId` 和 `activityId` 找到 Activity 定义，再将 `attributeValues` 转换为可搜索文字：文本/数字属性读取 `value`，单选/多选属性读取对应选项的 `label`。转换后的文字与 `log.note` 一起交给现有备注分组匹配逻辑，因此空格仍表示 AND，OR 仍只在同一组内生效。

## 兼容性

- 没有属性定义、没有属性值或历史属性选项已删除时，仍保留备注原有行为。
- 属性名称永远不会加入可搜索文本。
- 其他筛选字段（标签、领域、待办、Reaction）不变。

## 验证

在 `src/utils/filterUtils.test.ts` 增加属性文本、数字、单选、多选值命中测试，验证属性名称不命中，并验证备注与属性值可以共同满足 AND/OR 条件。运行筛选工具测试和生产构建。
