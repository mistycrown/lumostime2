# 三个设置选项列表的卡片宽度设计

## 背景

新版导航背景、导航图标方案、心情日历背景三个设置列表目前使用等分网格。选项数量较少时，卡片会被拉伸到整行，导致视觉比例偏大。

## 方案

三个列表统一使用左对齐的 CSS Grid 可换行布局，每个选项卡片最大宽度为 `96px`，网格轨道使用 `repeat(auto-fill, 96px)`，从根源上取消剩余空间分配。这样在桌面或较宽容器中，卡片不会因选项少而无限拉伸；临界宽度下也不会因 flex 的整行宽度计算出现异常折行。

## 范围

- `NavigationBackgroundSelector`：新版导航背景及添加卡片。
- `NavigationIconSelector`：文字、粉色、自定义方案卡片。
- `MoodCalendarBackgroundSelector`：心情日历背景及添加卡片。

不改变选项选择、上传、删除、排序或响应式断点行为，仅调整布局尺寸与对齐方式。

## 验证

- 选项较少时卡片保持最大宽度并左对齐。
- 选项较多时按固定间距自动换行。
- 窄屏幕下无横向溢出。
- 运行 `npm run build`。
