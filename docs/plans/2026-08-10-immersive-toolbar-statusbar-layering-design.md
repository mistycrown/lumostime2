# 沉浸式顶部工具栏与状态栏背景分层设计

## 问题

横屏沉浸式计时中，为避免 Android 状态栏恢复成白色而加入的黑色原生背景 View 位于 Capacitor WebView 之上。该 View 因而遮住网页层固定在顶部的工具按钮。

## 方案

沉浸式状态下，将原生状态栏背景 View 重排至 `android.R.id.content` 的第 0 层。WebView 与其顶部工具栏会位于黑色背景之上，保持原有位置和点击区域；黑色背景仍覆盖状态栏区域。

退出沉浸式时，将该背景 View 恢复到前景，保留普通页面状态栏着色逻辑。

## 验证

- 横屏进入沉浸式后，顶部按钮显示在黑色状态栏区域内并可点击。
- 顶部不再出现白条。
- 竖屏沉浸式、退出沉浸式与普通页面状态栏外观保持正常。
