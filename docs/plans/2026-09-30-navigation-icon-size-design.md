# 导航栏图标大小设置设计

## 目标

让用户在新版导航的图片图标方案中调节图标大小，并允许主题包 JSON 在导入时指定同一数值。文字导航不受影响。

## 方案

在现有 `navigation_icon_selection_v1` 选择对象中增加 `iconScale`，以百分比表示，默认 `100`，有效范围为 `70` 至 `140`。导航图标服务负责读取、规范化和保存该字段，并复用既有 `navigationIconChange` 事件通知页面实时刷新。

`NavigationIconSelector` 在图片图标方案下提供一个滑杆设置项。`BottomNavigation` 保留当前 28px（移动端）与 36px（桌面端）的基准尺寸，并按 `iconScale / 100` 计算图片图标的实际尺寸；导航文字与文字导航样式保持不变。

主题包可在 `apply.navigation.iconScale` 中指定数值。主题包创建服务会保留此字段，验证器拒绝非数值或超出 70–140 的值，导入应用时与 `showLabelWithIcon` 一起写入导航图标选择对象。省略字段时保留用户当前图标大小，确保旧主题和旧设置继续按 100% 工作。

## 验证

- 服务测试覆盖默认值、范围钳制和持久化。
- 主题包测试覆盖合法字段保留、非法值拒绝及导入应用。
- 更新主题包模板与格式说明，示例使用 `iconScale`。
- 运行相关 Vitest 测试与 `npm run build`。
