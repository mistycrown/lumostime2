# 旧版主题预设的新版外观默认值

## 目标

旧版内置主题在切换时必须显式恢复新版导航栏与 Memoir 日历的默认选择，避免遗留上一个新版主题的外观状态；用户上传的素材库不受影响。

## 方案

扩展 `ThemePreset` 的可选外观配置字段。每个内置旧版预设显式提供以下默认值：

- 新版导航背景关闭，当前背景为默认项。
- 导航图标为文字模式，图标标签关闭。
- 透明导航关闭。
- Memoir 日历背景为“无”。

主题预设的通用应用服务只在预设提供相应字段时持久化并触发服务更新；因此自定义快照主题继续由快照恢复逻辑完整还原，不会被旧版默认值覆盖。

## 验证

新增服务测试：预设应用前设置新版导航背景、导航图标、透明导航与 Memoir 日历背景；应用带默认字段的旧版预设后，断言这些当前选择均恢复默认，并断言素材列表键没有被清空。
