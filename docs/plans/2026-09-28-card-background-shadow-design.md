# 卡片背景浅阴影设计

## 目标

当用户启用自定义卡片背景且图片成功加载时，为对应卡片提供克制的浅阴影，帮助卡片从页面背景中轻微浮起；默认无背景卡片的视觉保持不变。

## 方案

由 `getCardBackgroundStyle` 统一产出阴影样式：`0 2px 8px rgba(0, 0, 0, 0.07)`。`useCardBackground` 仅在实际取得图片 URL 时将该样式和 `active: true` 一并交给使用方，因此已接入该 Hook 的场景卡、松散待办、复盘卡片与回忆总结卡片会同步获得阴影，未启用或加载失败时不会有阴影。

## 验证

扩展卡片背景服务的单元测试，断言生成的启用背景样式包含预期阴影；运行相关 Vitest 测试和生产构建。
