# 悬浮按钮背景方案库设计

## 目标

将现有全局单张悬浮按钮背景升级为与新版导航背景一致的“多个自定义方案 + 当前选择”模型。上传新图片后自动成为当前方案；用户可在“投喂小鱼干 → 样式”中选择、调节和删除方案。

## 数据模型与迁移

设置服务保存自定义方案数组和当前方案 ID。每个方案具有稳定 ID、图片文件名和独立缩放值（50–200，默认 100）。没有选中自定义方案时，当前 ID 为空并使用默认按钮外观。

保留原有单图文件名和缩放键的读取迁移：检测到旧配置且不存在方案库时，创建一个方案并自动选中。迁移后只写新方案库和当前 ID，确保已有用户图片不会丢失。

## 样式与交互

“悬浮按钮背景”区块改为方案缩略图网格：默认项、所有自定义方案和上传项。上传新图会创建并选中方案；点击缩略图切换当前方案；选中项显示其图片大小滑杆；自定义方案提供删除入口。删除当前方案后回退至默认按钮，图片仅在未被其他设置或主题快照引用时删除。

选中自定义方案时，`FloatingButton` 保留圆形裁切图片与图标，但移除组件原有的背景色、边框和阴影。未选中方案时完整保留既有主题样式。按钮位置、尺寸、点击行为和图标层级均不改变。

## 主题与资源

备份、完整主题快照和图片引用收集保存整个方案库与当前选择；因此“保存当前设置为方案”会保留可选按钮方案，不只保存正在使用的一项。

主题 ZIP v2 的 `resources.floatingButtonBackgrounds` 支持多条资源；`apply.floatingButtonBackground` 继续指定当前 `resourceId` 和缩放。导入时将全部资源注册为用户可选方案，仅选中的资源成为当前项；主题资源的更新、删除和引用清理沿用现有包资源规则。

## 验证

- 覆盖旧单图迁移、创建/选择/删除方案、独立缩放和引用保护。
- 覆盖选中方案时没有按钮背景、边框和阴影，默认项恢复原样。
- 覆盖多资源主题 ZIP 的校验、导入注册和当前选择。
- 运行定向 Vitest 测试及 `npm run build`。
