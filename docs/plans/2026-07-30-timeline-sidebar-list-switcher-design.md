# 时间轴侧栏待办列表切换

## 目标

允许用户在时间轴右侧待办栏中，从当天排期待办切换到任意正常待办分类或系统“小事”，并保证任务层级清楚可用。

## 交互

- 侧栏展开时，在现有展开/收缩控制下方显示同规格的列表切换按钮；侧栏收起时不显示。
- 按钮打开轻量选择弹窗，提供“当天待办”、全部用户待办分类和“小事”，排除“未来”。
- 选择只在当前时间轴页面会话中生效；重新进入页面默认显示当天待办。
- 回顾入口始终保留；日课仅在“当天待办”模式显示。

## 数据与层级

- 当天模式保留当前排期、截止、重复、备选和置顶任务的来源逻辑。
- 分类模式按 `categoryId` 筛选任务；小事通过其保留分类 ID 识别。
- 两种模式均先建立一层父子树。父任务作为根行，子任务按 `childOrder` 缩进并可展开；子任务不会重复作为根行。
- 子任务继承父排期，因此当天模式会显示命中当日的子任务。

## 验证

为列表选项、分类过滤和排期子任务树添加单元测试，并执行相关 Vitest 测试和生产构建。
