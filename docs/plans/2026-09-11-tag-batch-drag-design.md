# 标签批量管理拖拽设计

## 目标

让标签批量管理中的二级标签可以通过明确的拖拽把手完成分类内排序和跨大分类迁移。

## 交互

- 每个二级标签条目最左侧的把手是唯一拖拽启动区域，避免输入框、颜色和操作按钮抢占原生拖拽事件。
- 拖到同一大分类的其他标签条目时，根据条目上半区或下半区插入到对应位置。
- 拖到其他大分类的标签列表或分类空白区域时，按落点插入；空列表则追加。
- 拖拽结束后清理拖拽状态；原有上下移动按钮继续保留。

## 数据流与边界

拖拽过程中只维护被拖标签、来源分类和当前悬停分类/条目。放置时基于当前 state 复制分类和活动数组，先从来源分类移除，再把活动插入目标分类，最后一次性更新本地编辑草稿。未提交前不触发持久化。

## 验证

使用 TypeScript/Vite 生产构建验证类型与编译；手动检查分类内排序、跨分类迁移和输入框正常编辑。
