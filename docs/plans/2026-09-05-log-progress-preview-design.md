# 编辑记录时的待办进度预览

日期：2026-09-05

## 目标

修复编辑已有进度记录时，待办进度预览将该记录的旧增量再次计算的问题。

## 规则

- 新建记录：显示待办当前已完成量。
- 编辑记录：显示该记录提交前的已完成量，即从当前已完成量中扣除该记录原有的 `progressIncrement`。
- 预览不叠加输入框中正在编辑的 `+N`；输入框继续单独表示本条记录将保存的进度。
- 更换关联待办时，仅原关联待办扣除旧记录增量，其他待办仍显示其当前完成量。

## 实现与验证

- 在 `todoProgressUtils.ts` 集中处理编辑记录的显示基线，避免组件自行重复判断。
- 记录弹窗只展示该基线，不改变现有保存时“先扣旧值、再加新值”的数据逻辑。
- 覆盖同待办编辑、新建或更换待办、以及旧数据不一致时不显示负数的回归测试。
