# 悬浮按钮自定义背景图片溢出设计

## 目标

修复右下角悬浮按钮使用自定义背景图片时的视觉裁剪问题。调整图片大小超过按钮尺寸后，图片应从按钮中心向外溢出显示，而不是被圆形背景层裁剪。

## 交互边界

- 悬浮按钮自身的尺寸、定位、圆形点击区域和点击行为保持不变。
- 只有自定义背景图片的视觉层允许超出按钮边界。
- 图标继续位于图片之上，并保持可见与可交互。
- 未选择自定义背景时，默认主题按钮样式完全不变。

## 实现方案

`FloatingButton` 将自定义背景从带 `rounded-full` 的 CSS `background-image` 层改为居中的 `<img>` 视觉层：

- 图片宽度使用现有方案的 `scale%` 值，保持当前缩放设置含义。
- 高度自动计算，保留原图片比例。
- 使用 `max-width: none` 防止全局图片最大宽度规则阻止溢出。
- 使用绝对定位和中心变换，让图片以按钮中心为基准向四周缩放。
- 使用 `pointer-events: none`，避免图片视觉层遮挡按钮点击。
- 不给图片层或其包裹层设置圆形裁剪。

背景方案服务、上传、缩放范围、主题包导入与默认样式逻辑不做改动。

## 验证

- 添加或更新 `FloatingButton` 组件测试，验证自定义背景使用图片元素、缩放百分比正确、图片层不接收指针事件且不使用圆形裁剪。
- 验证未设置自定义背景时仍使用原有主题样式。
- 运行相关 Vitest 测试。
- 运行 `npm run build`。
