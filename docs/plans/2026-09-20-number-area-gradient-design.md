# 数值面积趋势渐变设计

## 目标

让数值面积趋势图的折线下方面积从折线附近的浅色逐步过渡到图表底部透明，减轻底部填充的视觉重量，同时保持折线、节点和其他数值图表不变。

## 实现

- 在现有面积趋势 SVG 中定义纵向 `linearGradient`。
- 顶部使用当前面积填充色和透明度，底部使用同色但透明度为 0。
- 仅 `numberArea` 分支使用该渐变，保持现有折线和节点绘制逻辑。
- 使用组件实例级唯一 ID，避免多个统计卡片之间的 SVG 渐变引用冲突。

## 验证

- 运行相关 Vitest 测试。
- 运行 `npm run build`，确认 TypeScript/生产构建无新增错误。
