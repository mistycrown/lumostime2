# 植物手帐主题包设计

## 目标

将 `docs/plans/theme-package-template - 副本` 整理为可导入的「植物手帐」主题包，展示名为“植物手帐”，稳定包 ID 为 `plant-journal`。

## 资源策略

- 保留全部现有图片；所有 PNG 转为 WebP，原 PNG 在转换验证后移除。
- 以资源用途规范命名：整体背景、导航背景、Memoir 背景、六张卡片背景、悬浮按钮背景和两组各 16 张贴纸。
- 不为缺失的字体与时间小友虚构资源。仅当“鼎烈宋体”为现有内置字体时，在 `apply.font` 写入对应内置 ID；否则省略字体配置。

## 配置策略

- 主题色为内置 `morandi-green`，UI 图标为内置纯文字 `pencil`。
- 整体背景透明度 0.92；导航背景垂直拉伸 115%；Memoir 背景透明度 0.90。
- 应用内置第 5 个成就瓶图标包、第 7 个成就瓶样式和第 2 个时间线样式；所有 ID 均以对应服务的实际顺序为准。
- 登记现有的背景、贴纸、卡片、导航、Memoir 与悬浮按钮资源；不写没有对应文件的资源类型。

## 验证

转换后检查无 PNG 残留、所有 `theme.json` 路径均存在、JSON 可解析，并使用项目主题包解析测试覆盖格式兼容性。
