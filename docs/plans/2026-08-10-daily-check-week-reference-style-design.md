# 日课周统计参考样式统一设计

## 目标

依据用户提供的参考图，统一日课周统计 4x4 与 4x3 小组件的标题栏、左右留白、星期栏和打卡单元视觉，不再保留两种尺寸各自独立的视觉语言。

## 共同样式

- 顶部仅显示日期范围，刷新图标紧跟在日期右侧，颜色为浅灰；移除“日课周统计”标题与分割线。
- 两种尺寸的顶部和内容区统一使用 16dp 左右内边距。
- 日期下方显示“日 一 二 三 四 五 六”星期栏，七列文字与打卡方格中心对齐。
- 未打卡状态为无描边的浅灰圆角方格。
- 已打卡状态为日课颜色对应的浅色圆角方格，使用深色且加粗的大对勾，不再使用白色小对勾。
- 日课图标与名称位于左侧，名称采用中等字重；七列打卡状态位于右侧。

## 尺寸差异

- 4x4 使用完整周表位图，容纳高度内的日课行；顶部栏由布局承载，便于将刷新按钮固定在日期旁。
- 4x3 使用固定行高的滚动列表，并新增与方格列共用坐标的星期栏位图；列表维持无滚动条、无回弹。

## 验证

- 用静态测试覆盖两个组件的共用星期栏、方格打卡样式、刷新路由与 4x3 无滚动条配置。
- 解析所有新增或修改的 Android 资源 XML。
- 运行周统计数据测试、Web 生产构建与 Capacitor Android 同步；不执行 Android Gradle 编译。
