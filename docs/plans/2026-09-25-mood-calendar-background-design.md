# Memoir 心情日历背景设置设计

## 目标

在“投喂小鱼干”页面增加心情日历背景设置，替换 Memoir 顶部 `MoodCalendar` 当前的白色卡片背景。背景支持内置图片、自定义上传、删除、选择，以及复用新版导航栏调节器进行位置、缩放和透明度调整。

## 范围

- 仅作用于 Memoir 顶部心情月历，不影响待办月历、时间线日历或统计日历。
- 默认保留“无背景”选项，现有界面在未选择图片时保持不变。
- 提供 `public/calendar/1.webp` 作为首个内置背景，并允许投喂用户上传自定义图片。

## 架构

新增独立的 `moodCalendarBackgroundService`，不复用导航栏当前图片和参数 key，避免两种 UI 的配置互相覆盖。服务负责内置/自定义素材列表、当前选择、每张图片的参数、图片持久化以及变更/预览事件。自定义图片沿用 `imageService` 的 `theme` 资源组。

配置结构包含：

- 当前背景 ID
- 自定义背景列表
- 每个背景的 `offsetX`、`offsetY`、`scale`、`opacity`
- 五周与六周的缩放映射值

## 渲染行为

`MoodCalendar` 外层改为相对定位。背景图片使用绝对定位层放在日期内容下面，设置 `pointer-events: none`，允许图片溢出日历容器，不使用 `overflow: hidden` 裁切。日期格、贴纸和按钮保持在前景层，交互行为不变。

月历按实际生成的周数计算映射：五周使用基础缩放，六周使用独立的六周缩放系数；X/Y 位置使用同一相对坐标。切换月份只改变映射结果，不改变用户保存的基础参数。调节器可以在五周/六周预览之间切换并分别调整对应缩放。

## 投喂页交互

在现有导航栏设置区域下加入“心情日历背景”区域，提供缩略图选择、上传、删除和“调整”入口。调整弹窗沿用导航栏调节器的移动、缩放、透明度控件，增加五周/六周预览切换与映射缩放控制。参数修改即时广播到 Memoir，保存后刷新仍保持。

## 兼容与错误处理

- 无效或缺失的当前背景 ID 回退到“无背景”。
- 自定义图片继续使用现有图片服务的本地持久化和主题资源清理机制。
- 内置图片加载失败时保持透明/原有背景，不阻塞日历交互。
- 删除当前自定义背景时自动回退到“无背景”。

## 验证

- 为服务增加参数读写、回退、删除和周数映射测试。
- 为 `MoodCalendar` 增加背景层和五周/六周映射渲染覆盖。
- 执行 `npm run build`，并手动检查投喂页选择/上传/调节/刷新持久化，以及 Memoir 五周、六周月份的显示。
