# 自定义筛选器支持 Todo 类别名设计

## 背景

当前自定义筛选器里的 `@关键词` 在日志筛选场景中只匹配关联 Todo 的标题，无法直接命中 Todo 类别名。对主要依赖类别组织任务的用户来说，这会让筛选表达式变长，也降低可维护性。

## 目标

将 `@关键词` 统一定义为：

- 在 Todo 目标筛选中匹配 `Todo 标题 + Todo 类别名`
- 在日志目标筛选中匹配 `关联 Todo 标题 + 关联 Todo 类别名`

这样用户可以直接写 `@计划`、`@工作` 之类的表达式，而不用枚举该类别下的每个 Todo 名称。

## 方案

1. 复用现有 `@` 前缀，不新增语法。
2. 在 `filterUtils.ts` 中统一 `@` 的匹配值集合，让日志筛选与 Todo 月视图隐藏筛选保持一致。
3. 补充回归测试，覆盖：
   - `@Todo标题`
   - `@Todo类别名`
   - `OR` 组合
   - 非目标类别不误命中
4. 更新设置页、批量管理、成就规则、用户指南中的文案说明。

## 非目标

- 不新增新的筛选前缀
- 不改变 `#`、`%`、`^`、无前缀备注 的既有语义
- 不修改 Todo 分类数据结构或存储格式
