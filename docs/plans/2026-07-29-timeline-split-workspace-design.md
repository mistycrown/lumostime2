# 脉络同层分栏工作区设计

## 背景

“时间轴 + 待办”布局当前把待办以绝对定位的侧栏渲染在页面上方，导致它覆盖而非参与主区域布局；回顾卡也位于时间轴滚动容器之外，不能随时间轴滚动。

## 决策

采用同层分栏工作区：日历保留在页面顶部，日历下方的主工作区占据剩余高度。回顾卡和时间轴置于左列的同一个纵向滚动流，待办置于右列，二者同高且按比例分割可用宽度。待办不再使用固定定位或抽屉覆盖页面。

在所有屏幕尺寸中，待办展开或收起均通过右侧屏幕边缘的控制按钮完成：展开时显示右列，收起时左侧时间轴占满工作区。较窄屏幕中展开后的两列使用较小但稳定的待办宽度；不再提供顶部菜单入口。

## 交互

- 回顾卡位于时间轴滚动内容的起点，向下滚动时与时间轴一同离开视口。
- 时间轴继续独立垂直滚动和双指缩放。
- 待办列独立垂直滚动，并保持底部安全留白，避免被页面悬浮按钮遮挡。
- 右边缘按钮始终可见，图标表达展开或收起状态。

## 验证

1. 收起时仅显示左列时间轴，右边缘仍有展开按钮。
2. 展开时时间轴与待办同时存在，待办不覆盖时间块，二者顶部和底部对齐。
3. 滚动时间轴时回顾卡随内容离开视口。
4. 窄屏展开、收起与待办滚动可用，生产构建通过。
