# 备注模板推荐设计

- 日期: 2026-04-19
- 主题: 分类/领域/标签详情内维护备注模板，并在补记与正在计时的备注区内联推荐

## 目标

- 不新增设置页入口，直接在分类详情、领域详情、标签详情里维护模板。
- 模板支持多条，每条包含名字与内容。
- 备注录入时不再弹出模板选择框，而是在备注框附近直接展示推荐模板，减少点击。

## 数据结构

- 新增 `NoteTemplate` 共享类型。
- 在 `Category`、`Scope`、`Activity` 上新增可选字段 `noteTemplates?: NoteTemplate[]`。
- 模板对象字段:
  - `id`
  - `name`
  - `content`
  - `order?`

## 详情页编辑

- 在分类、领域、标签详情页的细节区新增“备注模板”卡片。
- 卡片内用胶囊样式展示已有模板，只显示模板名。
- 点击“添加模板”打开弹窗编辑名字和内容。
- 点击已有胶囊打开同一弹窗进行编辑或删除。

## 备注区推荐

- `AddLogModal` 与 `FocusDetailView` 继续保留备注框上方的“推荐关联”区域。
- 在备注输入框下方新增“推荐模板”区域，直接显示可点选的模板胶囊。
- 模板来源按顺序聚合:
  - 当前标签
  - 当前分类
  - 当前领域
  - 待办关联出的标签
  - 待办关联出的分类
  - 待办关联出的领域
- 相同实体模板去重，保持首次出现的优先级。

## 插入规则

- 备注为空时，直接填入模板内容。
- 备注已有内容时，在末尾补一个换行后追加模板内容。
- 不做自动去重，允许用户重复插入同一模板。

## 复用实现

- 使用 `noteTemplateUtils.ts` 统一推荐排序与插入逻辑。
- 使用共享模板编辑弹窗与模板管理卡片，避免三类详情页重复实现。

## 验证

- 构建: `npm run build`
- 测试: `npx vitest run src/utils/noteTemplateUtils.test.ts`
