# 新版导航无背景选项设计

## 需求

新版导航背景列表需要支持“无背景”。该选项代表回到原版默认导航栏外观，而不是使用透明导航栏。

## 设计

- 在 `navigationBackgroundService` 的内置背景列表中增加 `new-none` 项，URL 为空并显示“无背景”。
- 选择器对无 URL 项渲染文字占位，不创建空图片请求。
- 底部导航仅在新版导航存在有效背景 URL 时使用透明导航表面；选择 `new-none` 后恢复原版按页面区分的半透明白色/米色导航表面和边框。
- 选择“无背景”时固定使用纯白不透明导航栏，优先于“标题栏透明”开关；其他导航背景仍遵循该开关。
- 现有默认背景、上传、删除和设置调整逻辑保持不变。

## 验证

- 列表出现“无背景”并可持久化选中。
- 选中后底部导航不渲染背景图片，并显示原版默认表面。
- 重新选择图片背景后恢复新版背景渲染。
- 运行 `npm run build`。
