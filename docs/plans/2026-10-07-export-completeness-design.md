# 导出完整性设计

## 目标

让 Obsidian 与 XLSX 导出覆盖当前日志模型中的属性及关键元数据，并修复已发现的日期范围与回顾导出问题；同时保持现有导出入口和使用方式不变。

## 方案

- Obsidian 继续输出可读 Markdown。在日志条目中补充标题、属性、评论、反应、计划/进度信息；在日报/周报/月报中补充摘要、心情、检查项和 AI Newspaper。节点、节点分类、待办和集合等独立数据以附加 Markdown 区块输出。
- XLSX 保留现有“时间记录”主表，新增属性动态列和完整日志元数据列；新增“属性定义”“待办”“节点”“节点分类”“集合”“集合条目”“日报”“周报”“月报”工作表，避免只导出展示字段。
- 导出范围统一由调用方先筛选，单日、范围、周报和月报不再混用全量日志；重复写入 Obsidian 文件改为覆盖，避免重复追加旧内容。

## 边界

图片文件仍沿用现有 Obsidian 附件复制流程；XLSX 中图片以文件名/标识符保存，不把二进制内容嵌入工作簿。属性列同时保留原始 JSON，属性定义表负责解释 ID、选项和单位。

## 验收

- 带有 text、number、single、multi 属性值的日志在两种导出中均可恢复。
- 历史日期的日报/周报/月报字段可被导出；单日统计只包含当天日志。
- XLSX 各工作表包含对应的当前数据集合，空集合也不会导致导出失败。
- 重复导出同一路径不会产生重复 Markdown 内容。
