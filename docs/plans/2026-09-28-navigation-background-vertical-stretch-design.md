# 新版导航背景纵向拉伸设计

## 目标

在新版导航栏背景的调试面板中增加“纵向拉伸”调节项，用于独立控制背景图片的高度。

## 交互与数据

- 新增 `verticalStretch` 设置，使用百分比，默认值为 `100`。
- 调试面板将该项置于“缩放”之后，提供与现有调节项一致的 `-5`、`-1`、`+1`、`+5` 控件。
- 值的范围为 `10%` 至 `300%`；调试时实时预览，点击“保存当前状态”后与其他背景设置一同持久化。
- 重置恢复为 `100%`；切换背景时读取该背景各自已保存的值。历史记录中字段缺失时视为 `100%`。

## 渲染

新版导航背景继续由“缩放”决定图片宽度。图片高度采用其按宽度计算出的原始高度，再乘以 `verticalStretch / 100`，从而只沿纵向拉伸，不改变横向尺寸或已有偏移、透明度行为。

## 范围与验证

- 修改新版导航背景的调试适配、持久化设置类型和新版图片样式。
- 旧版导航装饰不使用该字段，行为保持不变。
- 添加或更新服务测试，覆盖默认兼容与保存读取；运行 `npm run build`。
