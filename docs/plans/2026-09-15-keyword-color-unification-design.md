\# 关键字颜色与属性关键字统一设计

## 目标

在标签详情中统一管理手动关键字和自定义属性选项关键字。关键字以可持久化颜色的胶囊显示，支持内置颜色和自定义色组；时间线月历只读取统一关键字字段。

## 数据模型

`Activity.keywords` 扩展为兼容旧字符串数组的对象数组：

```ts
interface ActivityKeyword {
  label: string;
  color?: string;
  source: 'manual' | 'attribute';
  attributeId?: string;
  optionId?: string;
}
```

读取旧 `string[]` 时规范化为手动关键字对象，并为缺失颜色随机分配内置颜色。属性关键字记录 `attributeId` 和 `optionId`，保证选项重命名可以同步到关键字对象。

属性被设置为关键字源时注册所有未归档选项；取消时移除该属性的关键字对象；再次开启时补回缺失选项并保留已有颜色。新增或更新活动时执行同步，避免属性关键字和定义脱节。

## 交互

每个关键字胶囊分为文本区和操作区。文本区点击打开颜色选择弹窗，操作区仅对 `manual` 关键字显示删除按钮。弹窗复用内置 `COLOR_OPTIONS` 与 `useCustomColors()`，选择后立即更新胶囊颜色并由活动自动保存；取消或点击外部关闭弹窗。

## 时间线

详情页将规范化后的关键字对象传给 `DetailTimelineCard`。月历图例、日历单元格和关键字匹配均使用统一关键字列表及对象颜色。备注文本和属性值的匹配规则保持不变，但不再由时间线组件从两个来源拼接关键字。

## 兼容与验证

- 保留旧 `string[]` 的读取和其他模块按 label 使用关键字的行为。
- 覆盖旧数据迁移、颜色默认分配、手动增删改色、属性关键字注册/清理/重注册、选项重命名同步。
- 运行关键字工具与详情组件测试，并执行 `npm run build`。
