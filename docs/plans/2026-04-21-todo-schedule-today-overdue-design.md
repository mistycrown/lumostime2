# Todo 排期今页过期分段与周视图标签收紧设计
日期：2026-04-21

## 目标
- 让周视图右侧多标签在缩写后贴得更紧，避免保留整列宽度造成的空白。
- 让 `排期 > 今` 除了显示今天命中的任务外，也显示已经 `Arrange` 或 `Due` 但尚未完成的过期任务。
- 让 `今` 页面里的今天任务与过期任务通过和 `周` 视图一致的分隔标题样式分开。

## 方案对比

### 方案 A：只改文案，不改布局和数据分段
优点：
- 改动最少。

缺点：
- 周视图右栏的空白问题不会解决。
- `今` 页面仍然无法容纳过期任务与今天任务的并存展示。

### 方案 B：收紧 badge 容器，并给 `今` 页面增加双 section
优点：
- 直接解决缩写后的宽度浪费。
- `今` 页面信息更完整，同时保持现有排期筛选结构。
- UI 风格可直接复用 `周` 的 section 分隔线，不需要新增视觉体系。

缺点：
- 需要在 `TodoView.tsx` 增加一层 section 组织逻辑。

### 结论
采用方案 B。

## 交互与展示
- 周视图右侧状态列改为按内容宽度收紧，不再给每个 badge 固定整行宽度。
- 当同一条目出现多个 badge 时，继续沿用已有缩写规则：
  - `Arrange -> Arr`
  - `Repeat -> Rep`
  - `Trace -> Tra`
  - `Due`、`Done` 保持不变
- `排期 > 今` 页面分成两个 section：
  - `今天 · M.D`
  - `过期未完成`
- 两个 section 之间使用和 `周` 页相同的标题加横线分隔样式。

## 数据规则
- `今天` section 继续沿用现有 `today` 命中逻辑。
- `过期未完成` section 额外收集：
  - `scheduledDate < today`
  - 或 `deadlineDate < today`
  - 且 `todo.isCompleted === false`
- 为避免重复，如果一条任务已经出现在 `今天` section，就不再重复出现在 `过期未完成` section。
- `今` 筛选顶部计数改为 `今天 + 过期未完成` 的可见条目总数。

## 涉及文件
- 修改：`src/views/TodoView.tsx`
- 更新：`src/views/README.md`

## 验证重点
- 周视图多 badge 行里，缩写标签之间更紧凑，不再保留明显右侧空白。
- `排期 > 今` 能同时看到今天任务和过期未完成任务。
- 只有过期任务、只有今天任务、两者同时存在时，空态与分隔线都正确。
- `明`、`周` 两个筛选的原有行为不变。
