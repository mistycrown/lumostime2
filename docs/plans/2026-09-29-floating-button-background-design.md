# 悬浮按钮图片背景设计

## 目标

在“投喂小鱼干 → 样式”新增全局悬浮按钮图片背景设置。用户可以上传一张图片、调整其缩放比例或清除该设置；图片以圆形裁切替换所有 `FloatingButton` 的原有圆形容器背景。该设置必须被保存到当前主题方案，并能作为资源和配置随主题 ZIP 导入。

## 范围与决策

- 所有引用 `FloatingButton` 的页面统一使用该图片背景，包括右下角主操作按钮、切换按钮和复盘阅读按钮。
- 按钮的图标、点击行为、尺寸、位置、层级和按压动画保持不变；图片仅替换圆形背景。
- 使用一张全局图片而非图片组或按页面配置，避免主题配置和资源管理产生不必要复杂度。
- 图片使用 `cover` 填满圆形区域并裁切，缩放范围为 50% 至 200%，默认值为 100%。未选择图片时保留现有 CSS 主题背景。

## 本地设置与界面

新增 `floatingButtonBackgroundService`，独立管理：

- 图片文件名（或无图片状态）；
- 图片缩放比例；
- 变更事件，供预览和全部悬浮按钮即时刷新。

上传图片复用 `imageService` 的 `theme` 图片组。服务限制为单张图片、图片 MIME 类型、单文件最大 10MB；替换或清除图片时仅在它未被其他设置或快照引用时删除旧文件。

“样式”tab 新增一个与卡片背景一致的设置区块，包含圆形实时预览、上传/替换、清除和“图片大小”滑杆。上传后在不刷新页面的情况下更新预览；清除后恢复现有主题圆形背景。

`FloatingButton` 读取该服务的当前设置：有图片时以绝对定位的圆形背景层渲染图片，使用 `background-size: <scale>%`、居中且不重复；内容图标保留在更高层。没有图片时不添加该背景层，沿用 `floating-button` 或调用方原有的禁用主题样式。

## 主题快照、备份与资源清理

将新的 localStorage 键加入外观备份集合和主题快照集合。图片文件名加入：

- 外观备份的图片引用收集；
- 已保存主题快照的图片引用收集与恢复前校验；
- 全局设置图片引用收集，防止清理仍被当前设置或其他方案使用的资源。

因此“保存当前设置为方案”通过既有完整外观快照自动保存该配置；应用主题方案、导出/恢复外观数据和删除主题方案均保留或清理图片的既有规则。

## 主题 ZIP v2

主题模板新增：

```json
{
  "resources": {
    "floatingButtonBackgrounds": [
      { "id": "flower-button", "image": "assets/floating-button-backgrounds/flower.webp" }
    ]
  },
  "apply": {
    "floatingButtonBackground": {
      "resourceId": "flower-button",
      "scale": 100
    }
  }
}
```

资源置于 `assets/floating-button-backgrounds/`。导入器校验资源集合为数组、资源 ID 唯一、图片路径引用存在、`apply` 选择的资源 ID 存在，以及缩放为 50 至 200 的数值。导入器将资源保存为主题图片，注册本地设置，并在应用该主题时选择该图片与缩放。缺少该节的现有 v1/v2 ZIP 继续可用。

## 验证

- 为新服务覆盖默认值、上传替换、清除、缩放钳制和引用保护。
- 为主题 ZIP 解析/导入覆盖有效图片资源、缺失资源引用和非法缩放。
- 为主题快照覆盖图片与缩放被捕获、恢复和引用收集。
- 手动检查上传、缩放、清除以及所有常见页面的 `FloatingButton`；运行 `npm run build`。
