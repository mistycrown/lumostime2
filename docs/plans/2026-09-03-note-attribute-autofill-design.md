# 备注匹配属性自动勾选设计

## 目标

在记录新增、记录编辑和专注结束页面中，输入备注时自动识别当前活动的选择类属性选项。备注包含选项名称时，自动勾选对应选项。

## 行为

- 仅处理 `single` 和 `multi` 属性，不处理文本、数字属性。
- 仅处理当前可见且未归档的属性选项。
- 单选属性命中多个选项时选择名称最长的选项，减少短词覆盖长词的误判。
- 多选属性可同时勾选所有命中的选项。
- 已经由用户手动选择或取消的属性视为人工控制，备注变化不再自动覆盖。
- 自动匹配只更新当前表单中的属性值，不修改活动属性定义。

## 实现

匹配算法放在 `activityAttributeUtils`，共享属性字段组件接收备注文本并在备注变化后调用。组件维护自动应用值和人工控制属性的临时状态；父组件继续使用已有的 `onChange` 保存链路，因此新增记录、编辑记录和专注会话复用同一套逻辑。

## 验证

为大小写不敏感匹配、单选最长命中、多选多命中、数字/文本跳过和条件属性可见性添加工具测试，并运行 Vitest 与生产构建。
