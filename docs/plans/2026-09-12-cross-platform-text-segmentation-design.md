# 跨平台属性文本分词设计

## 背景

属性统计当前依赖浏览器 `Intl.Segmenter`。桌面 Chromium 与 Android WebView 使用的 ICU 版本和中文词典不同，导致同一文本在电脑端按词切分、安卓端退化为单字切分。

## 目标

- PC、Electron、Android 使用同一套中文分词逻辑。
- 无空格中文文本尽量得到自然中文词组，而不是逐字符结果。
- 继续过滤标点、空白和停用词，保持现有统计展示行为。
- 分词资源体积可控，并且只在属性统计需要时加载。

## 方案

采用浏览器可运行的固定版本 JS/WASM 分词器及中文词典，作为 `getTextTerms` 的唯一主路径。词典随 Vite Web 资源进入 Capacitor APK，因此 Android 不再依赖系统 WebView 的中文分词能力。`Intl.Segmenter` 仅作为资源加载失败时的降级路径。

文本处理流程：

1. 规范化首尾空白和换行。
2. 分词器输出中英文、数字及中文词组。
3. 应用现有停用词和合法字符过滤。
4. 统计组件按词频聚合。

显式空格和标点仍作为强边界，保证用户已经写出的词边界不会被模型重新合并。

## 加载与错误处理

分词器采用单例懒加载，首次打开属性统计时初始化；初始化期间保留确定性文本兜底，不阻塞页面。模型或词典加载失败时记录可诊断错误，并使用现有规则继续展示结果。

## 测试

- 固定测试中文短语和无空格句子，锁定词组输出。
- 覆盖显式空格、标点、英文、数字和停用词。
- 模拟分词器不可用及 Android 单字退化场景。
- 运行属性统计单元测试和 `npm run build`，检查最终资源体积。
