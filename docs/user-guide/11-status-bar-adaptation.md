# 状态栏自适应

## 功能介绍

LumosTime 现在支持根据背景图片自动调整手机状态栏的颜色，让状态栏与应用界面完美融合，不再出现割裂感。

## 如何使用

### 自动适配

当你在「个性化设置」中更改背景图片时，应用会自动：

1. 分析背景图片顶部区域的颜色
2. 计算背景的亮度
3. 自动调整状态栏图标颜色：
   - 深色背景 → 浅色图标（白色）
   - 浅色背景 → 深色图标（黑色）

### 效果展示

- **深色背景**（如夜晚、黑色主题）：状态栏图标显示为白色
- **浅色背景**（如白天、明亮主题）：状态栏图标显示为黑色
- **默认背景**：状态栏保持浅色图标

## 适用场景

- 切换不同风格的背景图片
- 使用自定义背景
- 调整背景透明度

## 技术细节

- 仅在 Android 和 iOS 设备上生效
- 在网页版中不会影响浏览器界面
- 分析算法针对图片顶部区域优化，确保与状态栏位置匹配

## 常见问题

### Q: 状态栏颜色没有变化？
A: 请确保：
1. 你正在使用 Android 或 iOS 设备（不是网页版）
2. 已经选择了非默认的背景图片
3. 应用有权限修改状态栏样式

### Q: 状态栏颜色不合适？
A: 系统会自动分析背景图片的亮度。如果效果不理想，可以尝试：
1. 选择对比度更明显的背景图片
2. 调整背景透明度
3. 使用其他背景图片

### Q: 沉浸式计时器中的状态栏？
A: 沉浸式计时器有自己的主题系统，会根据选择的主题独立设置状态栏。退出沉浸式模式后，状态栏会自动恢复到与背景匹配的样式。

## 相关设置

- 个性化设置 → 背景图片
- 个性化设置 → 背景透明度
