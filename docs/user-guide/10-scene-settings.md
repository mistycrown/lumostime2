# 场景设置

## 为什么需要场景设置？

### 待办清单的困境

你是否有过这样的经历：

- 打开待办清单，看着几十个任务，不知道从哪个开始
- 完成一个任务后，又要重新思考「接下来做什么」
- 一天结束时，虽然很忙碌，但感觉没有真正推进重要的事

这不是你的问题，而是**待办清单模式**的局限。

待办清单是一种「被动响应」的工作方式：
- 它告诉你「有什么要做」
- 但不告诉你「什么时候做」
- 更不告诉你「如何开始」

每次从清单中选择任务，都是一次**微决策**。而人的决策能力是有限的——这就是心理学中的「决策疲劳」（Decision Fatigue）。

### 时间块管理法：一种更主动的方式

**时间块管理法**（Time Blocking）是一种将时间主动划分为专注块的方法，由计算机科学家 Cal Newport 在《深度工作》（Deep Work）一书中系统阐述。

核心理念很简单：

> 不要让待办清单决定你的一天，而是**提前为每个时间段分配明确的主题**。

**重要区分：任务（Task）vs 事件（Event）**

在开始之前，我们需要理解两个概念的区别：

- **事件（Event）**：固定的、必须在特定时间发生的事情
  - 例如：10:00 的会议、15:30 的医生预约
  - 特点：时间固定，无法随意调整

- **任务（Task）**：灵活的、可以调整顺序和时间的事情
  - 例如：写代码、写文章、阅读
  - 特点：可以提前、延后、暂停、改变顺序

**时间块管理的核心：为任务分配时间，而非把任务放进日历**

很多人误解了时间块管理，以为是：
- ❌ 把每个任务都安排到具体时间：「10:00-11:00 写论文第三章」「11:00-12:00 回复邮件」
- ❌ 把任务当成事件，必须在指定时间完成

这种做法会导致：
- 不断重新安排时间块（因为任务总是做不完或被打断）
- 产生愧疚感（因为没有按计划执行）
- 系统失效（因为现实太灵活，计划太僵硬）

**正确的做法是：为任务类型分配时间块**

- ✅ 「上午 9-12 点是深度工作时间」—— 在这个时间块内，你可以做任何深度工作任务
- ✅ 「下午 2-4 点是沟通时间」—— 在这个时间块内，你可以回复邮件、开会、处理沟通
- ✅ 「晚上 10-11 点是复盘时间」—— 在这个时间块内，你可以回顾、写日记、查看统计

区别在于：
- **时间块是主题，不是具体任务**
- **你在时间块内有选择的自由**
- **但时间块的主题是确定的**

这种方法的优势：

1. **减少认知负荷**  
   不需要反复思考「接下来做什么」，因为时间块已经告诉你「现在是什么类型的时间」。

2. **降低场景切换成本**  
   研究表明，频繁的任务切换会导致高达 40% 的生产力损失。时间块管理通过将相似任务集中在同一时段，减少了大脑的「上下文切换」。

3. **创造深度工作的可能**  
   当你知道「上午 9-12 点是深度工作时间」，你会更容易进入专注状态，而不是被邮件、消息打断。

4. **保持灵活性**  
   你不需要提前决定「具体做哪个任务」，只需要知道「这段时间的主题是什么」。

### 从习惯到仪式：时间的意义化

时间块管理不仅是效率工具，更是一种**时间的仪式化**。

心理学研究区分了两个概念：

- **习惯（Habit）**：自动化的行为，由环境触发，无需意识参与
- **仪式（Ritual）**：有意识的行为，承载意义，标记身份转换

仪式的力量在于：
- 它**标记转换**：从「起床状态」进入「工作状态」
- 它**强化身份**：「我是一个重视晨间时光的人」
- 它**赋予意义**：不只是「洗漱」，而是「以洁净之心，迎接清晨的光」

场景设置正是将时间块管理与仪式感结合的实践。

## 什么是场景设置？

### 核心概念

**场景**是时间段与快捷方式的组合：

```
场景 = 时间段（如「早晨 6:00-9:00」）+ 快捷方式集合（如「起床喝水」「洗漱」「早餐」）
```

它不是一个独立的数据系统，而是对现有功能的**场景化整合**：

- **计时卡片** → 关联到标签（第3章）
- **待办卡片** → 关联到项目（第2章）
- **日课卡片** → 关联到习惯（第6章）
- **统计卡片** → 实时查看数据（第5章）
- **导航卡片** → 跳转到回顾（第6章）
- **原则卡片** → 提醒价值观（原则库）
- **引用卡片** → 引用之前回顾的回答（第6章）

### 场景的自动切换

场景会根据当前时间**自动切换**：

- 早晨 6:00，自动切换到「早晨场景」
- 上午 9:00，自动切换到「上午场景」
- 晚上 22:00，自动切换到「深夜场景」

你也可以手动切换到其他时间段，查看或提前准备。

### 场景与其他功能的关系

场景设置是 LumosTime 功能体系的**整合层**。如果说标签、待办、日课是「原子功能」，那么场景就是将这些原子组合成「分子」的方式。

通过场景，你可以：
- 用计时卡片快速启动标签活动（第3章）
- 用待办卡片聚焦项目（第2章）
- 用日课卡片习惯打卡（第6章）
- 用统计卡片实时查看数据（第5章）
- 用导航卡片快速跳转到回顾（第6章）
- 用原则卡片提醒价值观（原则库）
- 用引用卡片回顾之前的回答（第6章）

## 如何使用场景？

### 进入场景视图

在**记录页面**右下角，有一个悬浮切换按钮：

- 点击按钮，在「标签视图」和「场景视图」之间切换
- 场景视图会自动显示当前时间段对应的场景
- 你可以通过顶部的时间段标签，手动切换到其他场景

### 七种卡片类型

场景中的每个快捷方式都是一张「卡片」，支持 7 种类型：

#### 1. 计时卡片 ⏱️

**作用**：快速启动某个活动的计时。

**配置**：
- 关联到某个标签（如「学习 - 编程」）
- 可选：开启「直接跳转沉浸式计时」，点击后自动进入专注模式
- 可选：配置应用启动器，自动打开关联的应用

**示例**：
- 正面：「在逻辑与创造之间，构筑你的世界」
- 反面：「专注的时光，是送给未来的礼物」

#### 2. 待办卡片 ✅

**作用**：聚焦某个项目，快速启动待办计时。

**配置**：
- 关联到某个待办项目（如「完成毕业论文第三章」）
- 可选：开启「直接跳转沉浸式计时」
- 可选：配置应用启动器

**示例**：
- 正面：「趁思维清明，攻克今日之峰」
- 反面：「每一步攀登，都让山顶更近一寸」

#### 3. 日课卡片 ✓

**作用**：快速打卡某个习惯。

**配置**：
- 关联到某个日课项（如「起床喝水」「整理床铺」）
- 支持手动日课和自动日课（自动日课根据活动记录自动判断完成状态）

**示例**：
- 正面：「整理空间，也是整理内心」
- 反面：「外在的秩序，带来内在的平静」

#### 4. 统计卡片 📊

**作用**：实时查看某些活动的累计时长。

**配置**：
- 选择要统计的活动（如「编程」「写作」「阅读」）
- 可选：设置目标（如「今日深度工作 ≥ 3小时」）
- 目标类型：最小值（至少）或最大值（不超过）

**示例**：
- 正面：「回望今日的专注时光」
- 反面：「每一分钟的投入，都在塑造更好的自己」
- 显示：「2h 30m / 3h」（进度条）

#### 5. 导航卡片 🧭

**作用**：快速跳转到回顾或统计页面。

**配置**：
- 选择跳转目标：
  - 今日回顾
  - 昨日回顾
  - 本周回顾
  - 今日统计
  - 本周统计

**示例**：
- 正面：「回望来时路」
- 反面：「每一天都是一次小小的人生」

#### 6. 原则卡片 💎

**作用**：提醒你的人生原则或价值观。

**为什么需要原则库？**

原则库不只是一些励志语录的集合，它有两个核心作用：

1. **体现你希望成为怎样的人**  
   原则是你的价值观和人生愿景的具体化。当你在场景中看到「痛苦 + 反思 = 进步」，你不只是在读一句话，而是在提醒自己：「我是一个从挫折中学习的人」。

   心理学家 James Clear 在《原子习惯》中提出：改变习惯最有效的方式，不是关注你想达成什么，而是关注你想成为谁。原则卡片就是这种「身份驱动」的实践——它时时提醒你践行人生愿景。

2. **参考他人是如何思考原则的**  
   Ray Dalio 在《原则》一书中说：「原则是应对现实的基本真理。」通过学习他人的原则（如 Dalio 的「拥抱现实」、Cal Newport 的「深度工作」），你可以站在巨人的肩膀上，形成自己的原则体系。

**配置**：
- 三种模式：
  - **手动输入**：自定义原则内容
  - **从原则库选择**：选择已保存的原则
  - **随机选取**：每次从原则库中随机显示

**示例**：
- 正面：「痛苦 + 反思 = 进步」
- 反面：「接受现实，从中学习」

#### 7. 引用卡片 📖

**作用**：引用之前回顾中的某个答案，帮助你回顾过去的思考。

**配置**：
- 选择来源：昨日回顾 / 上周回顾 / 上月回顾
- 选择问题：从该回顾的引导模板中选择
- 设置兜底文案：如果该日期没有回顾，显示的默认文字

**示例**：
- 正面：「昨日改进」
- 反面：自动显示昨日回顾中「今日有哪些可以改进的地方？」的答案

### 卡片的正反面

每张卡片都有**正面**和**反面**：

- **正面**：行动前的提醒、激励、或问题
- **反面**：完成后的反思、确认、或答案

点击卡片，它会翻转到反面。

**如何撰写有效的卡片文案？**

1. **正面：降低启动成本**
   - 不要写「开始学习」，而是「趁思维清明，攻克今日之峰」
   - 用诗意的语言，赋予行动意义

2. **反面：强化完成感**
   - 不要写「完成了」，而是「每一步攀登，都让山顶更近一寸」
   - 用肯定的语言，强化正向反馈

3. **引用经典**
   - 可以引用书籍、哲学家的名言
   - 如「未经审视的人生不值得过」—— 苏格拉底

## 如何配置场景？

### 进入场景设置

在**设置页面**，找到「场景设置」入口。

### 时间段管理

#### 添加时间段

1. 点击「添加时间段」
2. 填写信息：
   - **名称**：如「早晨」「上午」「深夜」
   - **图标**：Emoji 或 UI 图标
   - **显示标题**（可选）：如果填写，场景页面顶部将显示此标题，而非时间段
   - **开始时间**：如 `06:00`
   - **结束时间**：如 `09:00`

#### 时间格式

- 输入 4 位数字，自动格式化为 `HH:MM`
- 例如：输入 `0600`，自动变为 `06:00`

#### 跨天时间段

支持跨天时间段，如「深夜 22:00 - 06:00」：
- 开始时间：`22:00`
- 结束时间：`06:00`
- 系统会自动识别这是一个跨天时间段

#### 时间段重叠检测

系统会自动检测时间段是否重叠：
- 如果新时间段与现有时间段重叠，会提示错误
- 跨天时间段也会正确检测重叠

### 快捷方式配置

#### 添加快捷方式

1. 选择一个时间段
2. 点击「添加快捷方式」
3. 选择卡片类型（计时/待办/日课/统计/导航/原则/引用）
4. 填写信息：
   - **标题**：卡片的主标题
   - **正面文字**（可选）：行动前的提醒
   - **反面文字**（可选）：完成后的反思
   - **卡片颜色**（可选）：自定义颜色，不选则使用默认颜色
5. 配置关联：
   - 计时卡片：选择标签
   - 待办卡片：选择待办项目
   - 日课卡片：选择日课项
   - 统计卡片：选择要统计的活动，设置目标
   - 导航卡片：选择跳转目标
   - 原则卡片：选择模式（手动/库选择/随机）
   - 引用卡片：选择来源和问题

#### 调整顺序

在快捷方式列表中，点击「上移」「下移」按钮，调整卡片顺序。

#### 编辑和删除

点击「编辑」按钮，修改卡片配置。  
点击「删除」按钮，删除卡片。

### 预设场景

系统提供了一套默认场景模板，包含 6 个时间段：

1. **早晨（6:00-9:00）**：起床喝水、整理床铺、洗漱、早餐、原则卡片
2. **上午（9:00-12:00）**：深度工作、原则卡片
3. **中午（12:00-14:00）**：午餐、午睡
4. **下午（14:00-18:00）**：编程、原则卡片
5. **晚上（18:00-22:00）**：晚餐、运动、阅读、写日记、今日回顾、感恩三件事
6. **深夜（22:00-6:00）**：今日深度工作统计、运动统计、摸鱼统计、今日统计、睡觉

如果你想重置为预设场景，点击右上角的「重置」按钮。

**注意**：重置会清除所有自定义配置，且无法撤销。

## 实践场景：如何用场景改变一天？

### 场景一：晨间仪式

**目标**：用仪式感开启新的一天，建立稳定的晨间习惯。

**时间段**：早晨 6:00-9:00

**卡片配置**：

1. **日课卡片：起床喝水**
   - 正面：「一杯清水，唤醒沉睡的细胞」
   - 反面：「身体开始苏醒，新的一天从此刻流淌」
   - 关联：日课模板中的「喝水」项

2. **日课卡片：整理床铺**
   - 正面：「整理空间，也是整理内心」
   - 反面：「外在的秩序，带来内在的平静」
   - 关联：日课模板中的「整理床铺」项

3. **计时卡片：洗漱**
   - 正面：「以洁净之心，迎接清晨的光」
   - 反面：「焕然一新，如同晨露洗过的叶片」
   - 关联：生活 - 洗漱

4. **计时卡片：早餐**
   - 正面：「用一顿好早餐，开启充实的一天」
   - 反面：「晨间的仪式感，从好好吃饭开始」
   - 关联：生活 - 饮食

5. **原则卡片：晨间价值观**
   - 正面：「痛苦 + 反思 = 进步」
   - 反面：「接受现实，从中学习」
   - 模式：从原则库选择

**使用流程**：

1. 早晨 6:00，打开 LumosTime，自动切换到「早晨场景」
2. 依次点击卡片，完成晨间仪式
3. 每张卡片的文案提醒你：这不只是「洗漱」，而是「以洁净之心，迎接清晨的光」
4. 完成所有卡片后，你已经建立了一个稳定的晨间节奏

**为什么有效？**

- **降低启动成本**：不需要思考「早上该做什么」，卡片已经告诉你了
- **仪式感**：诗意的文案让日常行为变得有意义
- **习惯养成**：每天重复相同的流程，大脑会逐渐自动化

### 场景二：深度工作

**目标**：进入心流状态，完成高认知负荷的工作。

**时间段**：上午 9:00-12:00

**卡片配置**：

1. **待办卡片：核心项目**
   - 正面：「趁思维清明，攻克今日之峰」
   - 反面：「每一步攀登，都让山顶更近一寸」
   - 关联：「完成毕业论文第三章」
   - 开启：直接跳转沉浸式计时

2. **原则卡片：深度工作原则**
   - 正面：「真理比正确更重要」
   - 反面：「保持开放心态，追求真相」
   - 模式：从原则库选择

3. **统计卡片：今日深度工作**
   - 正面：「回望今日的专注时光」
   - 反面：「每一分钟的投入，都在塑造更好的自己」
   - 统计：编程 + 写作 + 阅读
   - 目标：≥ 4 小时

**使用流程**：

1. 上午 9:00，切换到「上午场景」
2. 点击「核心项目」卡片，自动进入沉浸式计时
3. 专注工作 2-3 小时
4. 中途休息时，查看「今日深度工作」统计卡片，了解进度

**为什么有效？**

- **聚焦单一任务**：待办卡片让你专注于最重要的项目
- **沉浸式计时**：自动进入专注模式，减少干扰
- **实时反馈**：统计卡片让你看到进度，增强动力

### 场景三：睡前复盘

**目标**：回顾一天的时间流向，进行深度复盘。

**时间段**：深夜 22:00-6:00

**卡片配置**：

1. **统计卡片：今日深度工作**
   - 正面：「回望今日的专注时光」
   - 统计：编程 + 写作 + 阅读
   - 目标：≥ 3 小时

2. **统计卡片：今日运动时长**
   - 正面：「身体的觉醒，从规律开始」
   - 统计：运动
   - 目标：≥ 30 分钟

3. **统计卡片：今日摸鱼时长**
   - 正面：「偶尔放空，也是生活的一部分」
   - 统计：聊天 + 网上冲浪 + 看剧 + 游戏

## 设计哲学：场景背后的思考

### 减少启动成本

**问题**：为什么我们总是拖延？

不是因为懒，而是因为**启动成本太高**。

当你想「开始学习」时，你需要：
1. 打开待办清单，选择一个任务
2. 打开 LumosTime，选择标签
3. 点击开始计时
4. 打开学习应用（如 Anki、VS Code）

这 4 步，每一步都是一次决策，每一次决策都在消耗意志力。

**场景的解决方案**：

- 点击「核心项目」卡片
- 自动开始计时
- 自动进入沉浸式模式
- 自动打开关联应用（如果配置了应用启动器）

从 4 步变成 1 步，启动成本降低了 75%。

**心理学原理**：

行为科学家 BJ Fogg 提出的「行为 = 动机 × 能力 × 提示」公式：
- **动机**：你想做这件事
- **能力**：你有能力做这件事
- **提示**：有东西提醒你做这件事

场景设置同时优化了三个要素：
- **提示**：卡片就是提示
- **能力**：一键启动，降低难度
- **动机**：诗意的文案，增强意义感

### 时间的仪式化

**问题**：为什么有些人能坚持晨跑，有些人不能？

不是因为意志力，而是因为**仪式感**。

心理学研究发现，仪式（Ritual）与习惯（Habit）的区别在于：
- **习惯**：自动化的行为，无需意识参与
- **仪式**：有意识的行为，承载意义

仪式的三个作用：

1. **标记转换**  
   从「起床状态」进入「工作状态」，需要一个心理转换。仪式就是这个转换的标记。

2. **强化身份**  
   「我是一个重视晨间时光的人」—— 仪式让你确认自己的身份。

3. **赋予意义**  
   不只是「洗漱」，而是「以洁净之心，迎接清晨的光」—— 仪式让日常行为变得有意义。

**场景的实践**：

- 卡片的正反面文案，就是仪式的语言
- 每次点击卡片，都是一次有意识的选择
- 每次翻转卡片，都是一次自我确认

### 数据驱动的反馈

**问题**：为什么我们总是高估自己的努力？

因为**感觉不等于事实**。

你觉得今天学习了很久，但数据显示只有 1.5 小时。  
你觉得今天没怎么摸鱼，但数据显示刷了 3 小时手机。

**场景的解决方案**：

统计卡片提供**实时反馈**：
- 不需要等到晚上复盘，随时可以查看进度
- 目标设置让你知道「还差多少」
- 进度条提供视觉化的反馈

**心理学原理**：

行为心理学中的「即时反馈」原则：
- 反馈越及时，行为调整越快
- 反馈越具体，改进方向越明确

统计卡片就是这种即时、具体的反馈机制。

### 场景化的整合

**问题**：为什么功能越多，反而越难用？

因为**认知负荷**。

LumosTime 有标签、待办、日课、回顾、统计、原则库……功能很多，但如果每个功能都是独立的，用户需要在多个页面之间跳转，认知负荷会很高。

**场景的解决方案**：

场景是一个**整合层**：
- 不是新增功能，而是将现有功能场景化
- 不是替代其他页面，而是提供快捷入口
- 不是增加复杂度，而是降低使用成本

**设计原则**：

- **原子功能**：标签、待办、日课、回顾、统计
- **分子场景**：将原子功能组合成场景
- **用户体验**：用户不需要理解系统架构，只需要使用场景

这就是「场景化整合」的设计哲学。

## 常见问题

### 1. 场景和标签视图有什么区别？

**标签视图**：
- 按标签分类显示所有活动
- 适合「我想记录某个活动」的场景
- 是一个「工具箱」，你需要自己选择工具

**场景视图**：
- 按时间段显示预设的快捷方式
- 适合「我想快速开始某个任务」的场景
- 是一个「工作流」，系统已经为你规划好了

两者不是替代关系，而是互补关系。

### 2. 我需要严格按照时间段执行吗？

不需要。

场景的时间段只是一个**建议**，不是强制要求。

- 如果你早上 7:00 起床，可以手动切换到「早晨场景」
- 如果你晚上 11:00 还在工作，可以继续使用「晚上场景」

场景的目的是**减少决策**，而不是**限制自由**。

### 3. 我可以不使用预设场景吗？

可以。

预设场景只是一个参考，你可以：
- 完全自定义时间段和卡片
- 删除不需要的卡片
- 添加自己的卡片

场景设置的灵活性很高，你可以根据自己的生活节奏调整。

### 4. 场景卡片和日课有什么区别？

**日课**：
- 是一个独立的功能（第6章）
- 用于记录每日习惯的完成情况
- 数据会被统计和汇总

**场景中的日课卡片**：
- 是日课功能的快捷入口
- 点击后会切换日课项的完成状态
- 数据与日课功能共享

简单来说，场景卡片是「快捷方式」，日课是「数据源」。

### 5. 我可以在多个时间段使用相同的卡片吗？

可以。

例如，你可以在「早晨」和「晚上」都添加「洗漱」卡片，它们会关联到同一个标签，但可以有不同的文案。

### 6. 统计卡片的数据是实时的吗？

是的。

统计卡片会每分钟自动更新一次，显示当天的累计时长。

如果你正在计时某个活动，统计卡片会实时反映进度。

## 小结

场景设置是 LumosTime 的**整合层**，它将时间块管理法、仪式感、数据反馈结合在一起，帮助你：

- **减少决策疲劳**：预设好每个时段该做什么
- **降低启动成本**：一键启动任务，无需多步操作
- **增强仪式感**：用诗意的文案，赋予时间意义
- **实时反馈**：统计卡片让你看到真实的时间流向

场景不是为了限制你，而是为了**解放你**——让你从「选择做什么」的焦虑中解放出来，专注于「把事情做好」。

> 「时间管理的本质，不是管理时间，而是管理自己。」

愿你在场景中，找到属于自己的节奏。
