# 原则库功能使用指南

## 功能简介
原则库是一个用于存储和管理核心原则的功能。每个原则包含标题、正面文字和反面文字三个字段，可以在场景中的原则卡片中引用。

## 访问入口
设置 → 原则库

## 主要功能

### 1. 查看原则
- 所有原则统一显示，包括默认预设和用户添加的原则
- 每个原则都可以编辑和删除

### 2. 添加原则
1. 点击"添加新原则"按钮
2. 填写以下信息：
   - 标题（必填）：原则的名称
   - 正面文字（必填）：卡片正面显示的内容
   - 反面文字（可选）：卡片反面显示的内容
3. 点击"创建"按钮保存

### 3. 编辑原则
- 所有原则都可以编辑
- 点击编辑按钮，修改内容后保存

### 4. 删除原则
- 所有原则都可以删除（包括默认预设）
- 点击删除按钮，确认后删除

### 5. 重置功能
- 位置：页面右上角的旋转箭头按钮
- 功能：将所有原则重置为默认预设状态
- 确认：使用模态框进行二次确认
- 警告：此操作不可撤销

## 在场景中使用原则

### 步骤
1. 打开"场景设置"
2. 选择一个时间段，添加或编辑"原则"类型的卡片
3. 在编辑表单中：
   - 点击"从原则库选择"按钮
   - 选择一个原则
   - 系统会自动填充标题、正面文字和反面文字
4. 也可以手动输入自定义内容
5. 保存卡片

### 效果
- 卡片正面显示原则的正面文字
- 翻转卡片后，反面显示原则的反面文字
- 可以作为日常提醒和激励

## 设计理念
原则库的设计遵循以下理念：
- 简洁：只包含必要的三个字段
- 灵活：既可以使用预设原则，也可以自定义
- 复用：一个原则可以在多个场景中使用
- 独立：原则库独立管理，不与场景卡片耦合

## 使用场景示例

### 场景1：晨间激励
- 时间段：06:00 - 08:00
- 原则卡片：拥抱现实
- 正面：痛苦 + 反思 = 进步
- 反面：接受现实，从中学习

### 场景2：工作时段
- 时间段：09:00 - 18:00
- 原则卡片：极度求真
- 正面：真理比正确更重要
- 反面：保持开放心态，追求真相

### 场景3：晚间复盘
- 时间段：20:00 - 22:00
- 原则卡片：五步流程
- 正面：目标 → 问题 → 诊断 → 方案 → 执行
- 反面：系统化解决问题

## 技术说明
- 数据存储：localStorage
- 存储键名：`lumostime_custom_principles`
- 事件通知：`principleLibraryChanged`
- UI风格：莫兰迪色系，与应用整体风格一致
