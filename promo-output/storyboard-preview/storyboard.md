# LumosTime 横屏宣传片镜头表

| 镜头 | 时长 | 核心表达 | 现有界面依据 |
| --- | ---: | --- | --- |
| 01 | 10s | 点击一次活动，记录立即开始。 | `RecordView`、`TimerFloating` |
| 02 | 10s | 一段段投入连成可读的当天。 | `TimelineView`、`CalendarWidget` |
| 03 | 10s | 活动、领域、目标和待办保持关联。 | `ScopeDetailView`、`MajorGoalCard` |
| 04 | 10s | 统计帮助理解时间，而非考核自己。 | `StatsView`、`PieChartView` |
| 05 | 10s | 自然语言会回到结构化时间记录。 | `AIBackfillChatModal`、应用结果卡 |
| 06 | 10s | Android NFC 让开始进入实际环境。 | `NFCSettingsView`、`RecordView` |
| 07 | 10s | 待办保留安排、推进和完成的项目轨迹。 | `TodoView`、`TimelineView` |
| 08 | 8s | 从开始，到看见自己。 | 品牌收束 |

总时长为 78 秒。各镜头按编号顺序播放；交接采用纸面背景、同一组低饱和语义色和“点落下/记录延展/关系连接/数据聚合”的运动语法。
