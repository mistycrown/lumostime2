# ShareCard 组件

## 功能概述
ShareCard 组件用于将时间记录转换为精美的排版图片卡片，方便用户在社交媒体上分享。

## 设计理念
- **极简主义**：减少卡片内部要素，保持视觉空旷
- **独立入口**：纯文字和图文各自选择、保留布局模板
- **摄影排版**：照片保持原比例，正文、日期和活动标签轻量呈现
- **主题色彩**：9种色彩；深色卡片在基础色上加深

## 组件结构

```
src/components/ShareCard/
├── constants.ts          # 主题和模板配置
├── types.ts             # TypeScript 类型定义
├── TemplateRenderer.tsx # 按纯文字/图文模式分派，隔离纯文字模式中的照片
├── TextTemplateRenderer.tsx # 现有6套文字排版
├── PhotoTemplateRenderer.tsx # 摄影日记、变迁及3套多图排版
├── ShareCardText.tsx     # 节点标签和正文排版
├── shareCardTheme.ts     # 深色卡片调色
└── README.md           # 本文档
```

## 使用方式

### 1. 入口
在记录详情页面点击分享按钮，进入 ShareView；顶部的“纯文字”和“图文”是两个排版入口。有照片的记录默认进入图文，无可用照片时图文入口禁用。

### 2. 功能特性
- **9种主题色彩**：水墨黑、朱砂红、竹青、靛蓝、极简白、胭脂粉、琥珀黄、紫藤、青灰
- **6套文字模板**：经典、古韵、现代、分割、变迁、玻璃
- **5套图文模板**：摄影日记、变迁、无缝长图、边框长图、胶片长图；3套长图仅在至少2张可用照片时提供
- **照片完整保留**：按记录顺序纵向排列，不裁切、不限制张数
- **高清导出**：2x 像素密度的 PNG 格式；高度随内容变化
- **极简设计**：仅显示必要信息，保持视觉空旷

### 3. 数据映射
Log 数据自动映射到卡片内容：
- `note` → 正文内容
- `images` → 图文模式的配图；纯文字模式不渲染照片
- `startTime` → 日期
- `Activity` → 活动标签（纯文字，无图标）

## 技术实现

### 依赖库
- `html-to-image`: 将 DOM 转换为图片
- `lucide-react`: 图标库

### 核心流程
1. 用户在记录详情页点击 Share 按钮
2. 打开 ShareView 页面，显示预览和编辑区域
3. 用户选择纯文字/图文入口、主题和模板
4. 从已解码的预览照片制作临时导出快照，再将 DOM 转换为高清 PNG
5. Web 下载到本地；原生端写入 Pictures/LumosTime

## 模板说明

### 1. 经典杂志 (magazine-classic)
- 居中排版，优雅大方
- 适合大多数场景
- 首字母放大效果
- 顶部显示活动标签和日期

### 2. 竖排古韵 (vertical-poetry)
- 传统竖排文字
- 适合诗歌和短文
- 中国风设计
- 极简元素，突出文字

### 3. 现代分割 (modern-split)
- 分割线、正文与底部活动标签
- 文字模板中已移除图片布局

### 4. 变迁 (film-story)
- 纯文字：加深主题色的卡片
- 图文：第一张照片作为虚化背景，卡片内的照片保持清晰
- 日期与活动标签靠右排列

### 5. 留白便签 (minimal-note)
- 极简风格
- 专注于文字本身
- 适合短文和引言
- 最大化留白空间

### 6. 磨砂玻璃 (glass-morphism)
- 原有渐变光晕与文字排版

### 图文模板
- `photo-diary`：相纸留白，照片下方放正文，右下角放日期
- `long-image`：无缝满宽照片拼接，正文与日期置于末尾
- `framed-long-image`：深色底上的拍立得相纸，每张照片附日期和序号
- `film-strip`：深色底片、琥珀色小帧号与照片日期
- 所有模板的正文共用 ShareCardText，支持节点标签显示

## UI 优化

### 主题选择器
- 9个圆形色块均匀分布
- 圆圈尺寸：32px × 32px
- 选中状态：ring 效果 + 放大
- 响应式布局，确保所有圆圈完整显示

### 视觉简化
- 移除所有 UI 图标（UI Code、UI Sleep 等）
- 仅保留活动标签的纯文字
- 移除领域标签
- 减少装饰元素，增加留白
