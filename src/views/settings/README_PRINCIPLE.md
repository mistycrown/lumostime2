# 原则库功能说明

## 功能概述
原则库是一个用于存储和管理核心原则的功能模块。用户可以在设置页面中创建、编辑和删除原则，这些原则可以在场景设置中的原则卡片中引用。

## 文件结构
- `PrincipleLibraryView.tsx` - 原则库设置页面组件

## 数据结构
```typescript
interface Principle {
    id: string;          // 唯一标识符
    title: string;       // 原则标题
    frontText: string;   // 正面文字
    backText: string;    // 反面文字
}
```

## 存储方式
- 预设原则：硬编码在组件中，不可删除但可以编辑（编辑后会创建为新的自定义原则）
- 自定义原则：存储在 `localStorage` 中，键名为 `lumostime_custom_principles`

## 预设原则
1. 拥抱现实
   - 正面：痛苦 + 反思 = 进步
   - 反面：接受现实，从中学习

2. 极度求真
   - 正面：真理比正确更重要
   - 反面：保持开放心态，追求真相

3. 五步流程
   - 正面：目标 → 问题 → 诊断 → 方案 → 执行
   - 反面：系统化解决问题

## 使用方式

### 在设置页面中管理原则
1. 打开设置页面
2. 点击"原则库"菜单项
3. 可以查看、添加、编辑、删除原则

### 在场景设置中���用原则
1. 打开场景设置
2. 编辑或创建原则类型的卡片
3. 在"正面文字"输入框上方会显示"从原则库选择"按钮
4. 点击按钮选择原则，会自动填充标题、正面文字和反面文字
5. 也可以手动输入自定义内容

## 事件通知
当原则库发生变化时，会触发 `principleLibraryChanged` 事件，场景设置页面会监听此事件并更新原则列表。

## UI 设计
- 遵循应用整体的莫兰迪色系设计风格
- 标题栏与其他设置页面保持一致
- 使用简洁的卡片式布局展示原则
- 编辑表单采用模态框样式，避免页面跳转
